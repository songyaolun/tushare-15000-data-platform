# 年化250%研究：逐笔账本与成交容量审计

八账户的资金算术通过独立核对，但尚不能证明成交容量成立。主账户holding15正常
成本的CAGR仍为155.8517%；最大一笔成交占当日总成交额27.50%，其中72笔超过10%。
不能把这条净值曲线当作已经验证可执行的收益，更没有达到250%目标。

## 冻结范围与默认行为

复跑47列冻结评分的baseline47、holding15，各含原筛选范围100万元和主板12万元，
每种账户各跑正常与双成本。两种账户的股票范围不同，结果差异不能全归因于本金。
期间仍为2021-10-18至2026-10-16，共1212交易日，按250日年化；全样本拟合和选参，
不构成样本外验证。年度收益、费用、回撤和失败参数组沿用[首轮报告](stockops-annual250-astra-20261020.md)。

成交证据导出的提交为 `4d9991971fa8a1d02a7402bb59b7f372354219e5`。
八账户的daily.csv、trades.csv、entries.csv均逐字节复现首轮产物。
新增观察器不参与信号、仓位、退出、现金、费用或订单定价决策。

## 独立核账与源数据核对

独立审计器不调用模拟器的费用或资金函数。从fills.csv、distributions.csv及
positions.csv重建逐笔手续费、成交后现金、分红应收与支付、送股锁定、逐日股数、
成本和净值，并核对已平仓成本、卖出净额与分红。八账户零算术错误，最大货币差异
为7.45×10⁻⁹元；审计容差为10⁻⁵元。旧的简化CSV审计不能完成这些检查，本次使用
新增证据补足，不追认旧审计拥有同样范围。

33885笔成交均按证券代码与实际执行日匹配到原始DuckDB daily表，成交额和OHLC
最大误差均为零；对应涨跌停边界也全部匹配且误差为零。执行顺序、信号在前及
卖出T+1检查无异常。原始成交量全部为有限正数，按“手×100股”另算股数参与率。
每日持仓价与其实际观察日的冻结原始收盘价一致。全部分红事件均匹配规范原文；
原文范围含23569条实施记录及4条已有明确来源的现金分红修正，本次未改原文。

金额单位按[Tushare官方daily文档](https://tushare.pro/document/2?doc_id=27)核对：
amount为千元，vol为手。源特征直接保留amount，事后参与率只乘1000一次。
本次没有新增历史PIT认证，也没有补齐该研究原有的配股及历史证券状态限制。

## 价格区间异常与执行边界

各账户有217至302笔成交价格超出当日OHLC范围。逐笔分类全部为买价高于最高价或
卖价低于最低价，由原有固定滑点假设在开盘极值处产生，方向均对策略不利。
因此不能据此认定收益被抬高；但这些数值也不是当日可观察的真实成交报价。
完整异常记录已保留，没有为消除异常删交易、改价格或重算原收益。

当前引擎未施加成交参与率上限，仍使用开盘先卖后买的日线代理。
全日成交额与成交量只能证明规模相对于当天市场的比例，无法证明开盘竞价、
同一分钟或交易冲击可承接，更不能用于当天开盘决策。后继实验必须先明确只用
过去可见流动性限制订单的方案及退出处理，再比较收益；不能继续用无容量约束的
参数搜索宣称解决250%目标。
