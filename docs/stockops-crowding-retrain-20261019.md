# Return80：行业交易拥挤度重训对照

这次重训不支持用拥挤度模型替换当前模型。完整五年正常/双倍成本年化从98.44%/87.48%，降至仅加拥挤度的87.52%/78.39%，以及同时加5日变化的91.98%/83.00%。后者在拥挤度可用区间的双倍成本年化有所提高，但回撤也从7.98%扩大至9.88%，没有形成稳定改善。

本轮固定原模型复杂度、标签和买卖规则，只新增行业拥挤度，以及拥挤度的5日变化。全部五年成熟样本用于拟合，没有金融验证集或测试集。软件测试另行执行。

拥挤度采用 StockOps 现有定义：同级公开行业成交额占比在过去365自然日（含当日）的平均秩百分位。复用领域算法，没有用换手率或个股成交额代替。

## 数据边界和重训范围

原始缓存 `p03-optimization-20261018/sector-history` 包含31个L1行业，2020-01-02至2026-10-16各1643日，共50933条行业日线，每日31/31个有限非负成交额。目录只有SW2021当前版本，不能把它当成每一天归档的历史目录。成员另有Y5918条、N2006条，沿用基准按纳入/退出日构建的行业矩阵，没有将今日成员倒填。

同期中证网报道确认2021版行业指数于2021-12-13正式推出。因此此前按新分类回溯的成交额不进入新增特征；满365自然日预热后，最早2022-12-13使用拥挤度。此后仅接受窗口全部预期交易日有完整行业分母的值。520690条候选中，417316条有当前拥挤度，415423条有5日变化；2021年全部未知，2022年仅3536条已知。历史未知值保留NaN，不补零。2023至2026少量缺失来自原行业归属未知。

这仍是供应商重建历史与提供的成员有效区间，不是当时归档的不可变数据。SW2014及分类切换前的完整分母尚未认证，**不能宣称已验证五年完整拥挤度覆盖或严格历史PIT**。现有36列行业特征和标签继承原基准的历史数据限制。行业分类标准PDF入口本次返回网页，没有将它记为已获取的历史目录证据。

训练行保持490655，按信号日等权，最后31个市场日不训练；其中390507条具有拥挤度。原36列逐项保留，新增模型分别37列、38列。参数固定：31叶、深5、1600轮、学习率0.05、叶最少1000样本、L2=1、max_bins=255、random_state=20261019、关闭early_stopping。未搜索参数、入场过滤或拥挤度退出规则，未改变4.5%止盈、8%止损、30日持有和原轮换。因此本轮只回答这些特征在固定重训条件下的效果，不证明拥挤度过滤或退出机制的效果。
