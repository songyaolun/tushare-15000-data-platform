# 首轮年化提高到155.85%

47列无现金质量模型下，将最长持有从30日缩短到15日，百万元原范围账户正常成本CAGR由151.39%提高到155.85%，双成本由138.00%提高到139.53%。这只是样本内小幅改善，距离250%目标仍有94.15个百分点。

本轮七组、28账户全部完成并通过独立CSV统计复算。主指标沿用250交易日年化，区间为2021-10-18至2026-10-16，共1212交易日。全五年拟合与选参，没有金融留出集，不能当作未来收益承诺。

## 验证范围与未解决的问题

默认四账户的daily、trades、entries逐字段复现旧47列结果，仅忽略family展示名称。28账户独立检查现金非负、敞口不超过100%、日期连续、CAGR、最大回撤、年度收益、逐笔净收益及平仓数；新增参数32项测试通过，18语句、10分支覆盖100%，Ruff和git diff检查通过。

独立CSV不能复原未导出的开仓批次、完整分红流水、每次订单手续费和成交量。因此费用与换手沿用原模拟器输出，不能声称完整资金流水已独立核清。entries.csv目前只有日期，下一步优先补齐研究成交证据并核对实际执行日、金额单位和成交额占比。

现有日线模拟没有逐笔参与率上限；先卖后买复用同日开盘价也缺少分钟级证据。即使后续名义CAGR达到250%，这些问题未解决前也不得关闭目标。首轮固定单股5%、行业40%和原现金约束，没有借杠杆或扩大容量提高结果。

本次没有改生产模型、App依赖、UI或调度；未在Mac实测。旧48列含有口径不统一的现金质量输入，只作历史受限证据，后续以主线程验证的新模型为额外基准。
