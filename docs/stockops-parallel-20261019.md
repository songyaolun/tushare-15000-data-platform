# Return80：12万元主板数据增量实验

本轮由四个独立研究分支测试资金连续变化、筹码成本结构、业绩预告修正与融资交易。
新增特征先单组测试；资金降低回撤、业绩提高年化后，追加一次两者组合的限定对照。
总预算为四个单组模型加一个组合模型，不继续遍历组合或阈值。未修改生产模型或买卖规则。

## 比较基准

账户从2021-10-18以12万元空仓启动，运行至2026-10-16，共1212交易日。
证券范围与产品`scope-v1-c0-s0`逐一核对5451只股票，3379只沪深主板可进入原候选资格检查。
主板过滤在每日一级行业限一只和Top10之前执行；全市场广度及原模型特征不变。
全部模型仍使用原全市场490655条成熟样本拟合，只改变各组新增特征，隔离变量。

止盈4.5%、止损8%、最长30交易日、次日开盘、追价上限5%及原配对替换保持。
单股5%、行业40%，弱市新买上限15%、其他100%，不强制平旧持仓。
实际股数按整手和可用现金计算；佣金万三且最低5元，分时期过户费、印花税，单边5bp滑点。
双倍成本同时提高费用与滑点并重新模拟，不能直接从收益中减常数；基础最低佣金5元
不随本金缩放，双倍成本情景实扣最低佣金也翻倍到10元。
费率是研究假设，不代表用户券商合同。

全部五年用于拟合和选参，没有金融验证/测试集；软件测试单独执行。
以下结果均为样本内比较，不代表未来收益。原100万元、不同证券范围的98.44%年化
不作为本轮比较基准，也不能将差额全部归因于本金或全部归因于证券范围。

## 数据契约与边界

- 资金：1238/1238个日期、6196147行，零错日和重复；同一moneyflow来源计算大单及
  特大单净流比例、5日比例、正流持续性及变化。原520690候选中520616条完整。
  74条缺失是历史代码302132.SZ，保留NaN且不影响主板账户。
- 筹码：仅使用同一响应内无量纲成本比例，避免未验证复权口径与日线价格混算；
  筹码属于估算，不是真实账户持仓，也不把接口winner_rate当作未来上涨概率。
  本轮1238日6528764条原始记录；138条上市前记录全为北交所920代码，181113条
  当前主表无法核对代码，均不进入特征。主板不存在上市前/未知上市日期记录。
- 业绩：按同报告期各ann_date保留版本，公告日之后才允许使用，first_ann_date不能
  把修订值提前。供应商历史重建不是当时不可变归档，不声称严格PIT认证。
- 融资：实际交易/余额通常次日上午公布，在19:30决策中保守滞后。历史资格探测发现
  上交所名单含晚于查询日才上市的股票，因此该名单不进入新特征；实际报告的融资
  余额不等于当时可新增融资的资格。不存在的记录保持NaN，不补零。
  1238日4472761条明细没有上市前融资记录；326条负偿还额及空值保留原文，对应
  新增特征置未知。原daily.amount与panel三条实值完全一致，均为千元，只转换为元一次。

## 软件与独立核验

统一审计及证券范围相关83项测试通过；资金11项、筹码14项、业绩31项、融资18项、
组合拼接13项测试通过，各新增特征模块100%行覆盖。原36列与490655成熟训练行未变，
五个新增模型全部520690条便携预测与训练器结果逐值一致。

共16个1212日账户通过独立CSV审计，包括4个同业绩已知候选范围账户。另由独立Agent
复算指标及逐日候选：筹码/融资4账户逐笔收益误差0，年化/回撤/逐年最大差8.88e-16；
业绩及同范围8账户最大差1.9984e-15；组合两账户年化最大差1.33e-15。
独立复核不是金融样本外检验；软件一致性也不保证数据供应商历史不可变。

12万元主板实验结论：筹码是较均衡的后续研究候选，业绩是年化较高但覆盖交互需要谨慎解释的候选；
资金、融资及资金＋业绩组合不支持以提升年化为由替换现有模型。生产策略继续保持原版。
