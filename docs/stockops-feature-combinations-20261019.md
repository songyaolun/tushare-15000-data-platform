# 新特征单组与组合结果

全部五年用于拟合与选择，以下均为样本内结果。基准是42列筹码＋业绩融合；生产模型未修改。

本轮已完成五组全部31个非空组合、两项价量单列和一项公告置换，共34个新模型、136个新账户，无训练或回放失败。解禁组未通过数据准入，单列为阻断项。基准另外做精确复现，不计入34模型。

按用户预先指定的“12万元、主板、正常成本年化最高”目标，选中48列的 `event+quality+valuation`：在42列筹码＋业绩基础上增加公告反应2列、盈利质量3列、盈利收益率1列，年化从105.43%升至122.54%，提高17.11个百分点；最大回撤从7.29%升至9.07%。双成本109.89%，基准93.12%。这是本轮有限候选集合内的样本内赢家，不是所有可用接口、特征或参数中的全局最优。

如果优先考虑回撤和数据完整度，45列的 `freefloat+valuation` 值得并列保留：正常120.45%、双成本110.09%，回撤6.86%／6.97%。它比正常年化赢家少2.09个百分点，但双成本略高、两种成本回撤更小，也不依赖覆盖稀疏的现金质量列。52列全加模型取得最高双成本年化110.75%，仅比该45列方案高0.66个百分点，双成本回撤却达9.39%；不能据此声称特征越多越好。

100万元原范围中，同一48列方案同时取得正常和双成本最高年化151.56%／140.73%，基准119.11%／109.43%；正常回撤9.13%，双成本10.69%，基准为9.35%／8.88%。这两个账户同时改变本金和筛选范围，不能把差距全部归于本金。

单组在主板正常成本下，盈利收益率111.12%最有效，自由流通105.88%略好于基准，公告101.08%、盈利质量104.31%、价量103.11%均低于基准。公告和盈利质量单加不优、合加盈利收益率后最好，说明本轮存在组合收益差异；这不是对经济因果的证明。公告置换95.81%也只是一项固定种子的诊断，不是显著性检验或样本外验证。

## 数据与解释边界

回放2021-10-18至2026-10-16，共1212个交易日，沿用每年250交易日年化口径。520690行完整候选，490655行已平仓且成熟的训练样本，最后成熟信号日2026-08-26。固定1600棵HGB树、31叶、深度5、学习率0.05、叶样本下限1000、L2=1、种子20261019，不启用early stopping。分数为净收益回归排序值，不是上涨概率。

本轮沿用已审执行器：Top10、行业名额、下一可成交开盘、5%追价、4.5%止盈、8%止损、30日最长持有和低效持仓替换。退出收盘触发后下一开盘执行；数据契约审计核对策略、账户和成本配置与42列基准逐项一致。双成本包含既有执行器中的费用／滑点假设变化，不是将最终收益简单减半。

五组均保留NaN，不因新增特征缺失删除候选或填零。现金质量列成熟训练仅57862/490655（11.79%）有效，完整候选72032/520690（13.83%）。现金流表Q1／Q3净利润字段经常缺失，传递到TTM；跨表核验仍有361条净利润不一致，故没有用利润表强行补齐。盈利收益率保留73条市值核验失败的NaN。预告未发布导致的无事件与真实缺行情分别记录。

解禁接口可用，但缺稳定批次与修订／取消／延期身份，真实相同公告身份有6200万和1.25亿股冲突，无法判定叠加或修订。本轮不使用解禁，不制造矩阵。供应商今日返回的历史不自动等于历史时点可见：公告时间过滤、前缀重建及因子点值核验均已做，但不宣称全部历史已严格PIT认证。

用户要求全五年拟合与选参，因此结果存在样本内选择偏差。双成本、逐年表和置换仍使用相同历史，不能当作金融留出集；本轮不推断未来年化、不报告因果增益。
