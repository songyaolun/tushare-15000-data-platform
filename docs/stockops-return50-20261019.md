# 五年样本内年化50%目标的研究结果

冻结方案的原成本净年化为 **50.4756%**，双倍成本为 **45.3994%**，达到本轮50%的样本内研究目标。原成本胜率71.6747%，最大回撤11.1374%。100万元本金在1212个交易日后为725.03万元。

主要改善来自重新建立非线性选股模型。旧经济评分的最高已测年化约25.04%；本轮旧评分只调整强市仓位后为25.75%。新模型保持原买卖与仓位规则时达到47.77%，再把强市新买入总仓上限从90%提高到100%，得到冻结结果。

全部模型使用2021-10-18至2026-10-16的同一五年全样本拟合和选择。按用户要求没有金融验证集或测试集，结果不代表独立样本外alpha、历史当时已知的模型权重或未来收益保证。50%是本轮目标，不是A股策略的已知上限。

## 冻结策略

**选股。**沿用原PIT资格与技术风控候选池。输入为16个固定连续特征及20种原有信号是否命中，共36列。连续特征包括个股短中期涨幅、KDJ、BOLL、ATR、均线距离、行业动量、行业广度与扩散等，不输入日期、股票代码、行业编号或未来收益。收盘按预测净收益从高到低取Top10，沿用条件预备候选机制。

模型为直方图梯度提升树，最多31叶、深度5、600轮、学习率0.05、每叶至少1000条记录、L2系数1。训练目标是原成本下4%止盈、8%止损、30日持有规则的已完成交易净收益，信号日期等权。490655条成熟标签参与训练，期末31个交易日不用于训练，避免只留下快速平仓的尾部样本；账户仍回放全部1212日。关闭early_stopping，实际内部验证样本数为0。训练标签为独立5万元交易预算，实际账户预算随净值变化，两者并不完全相同。

**买入。**信号日收盘生成次日单日有效订单，下一可成交开盘执行，最高允许相对信号收盘复权价格上涨5%。单股目标上限5%，行业上限25%。市场广度达到40%时，新买入总仓上限100%，否则15%；广度是站上20日均线股票的比例。仓位状态只读取前一收盘数据，不主动按新上限强制清仓。

已有卖单可以准备额外买入候选，但必须等实际卖出成交后才释放对应名额和现金。继续检查停牌、涨跌停、整手、T+1、行业限额、分红和送股。没有杠杆或提前融资。

**卖出。**收盘达到4%盈利、8%亏损或30日持有期限后，下一可成交开盘退出。冻结方案不启用本轮额外状态早退。4%和8%是触发条件，成交价可能因隔夜跳空、不可成交或公司行动处理而偏离；不将亏损截断在8%。

## 探索过程与失败方案

本轮保留集中持仓44账户、简单排序20账户、市场仓位26账户、非线性模型及基准14账户、模型买卖交互10账户、达标后参数邻域6账户，共120个正式账户，包含必要的基准复现，不等于120种独立策略。核账中断产生的一份原始结果另行保留，不计入正式账户数。

集中持仓将单股提高到10%—20%，并比较Top1、2、3、5、8、10，最高连同退出交互仅20.39%原成本年化。简单按涨跌幅、相对行业强弱、扩散或波动率排序，最好为低波动率优先的5.82%。旧评分长期保持90%仓位时年化20.47%、回撤26.51%，不支持单靠提高暴露突破。

非线性实验先冻结六个复杂度配置，再逐个训练和两档成本回放。执行规则均固定为4%／8%／30日、5%单股、广度15%／90%。

| 叶数／深度／轮数 | 原成本年化 | 双倍成本年化 |
|---|---:|---:|
| 7／3／200 | 22.6255% | 15.6788% |
| 7／3／500 | 25.5934% | 20.4023% |
| 15／4／200 | 27.2099% | 19.3559% |
| 15／4／500 | 35.7022% | 31.7826% |
| 31／5／300 | 36.4194% | 31.9081% |

模型复杂度提高伴随明显的样本内收益提高，也增加了记住本段历史关系的可能。没有金融留出数据，不能将这种提升解释成泛化能力已获证明。模型训练分裂增益主要来自行业动量、行业广度和行业扩散，合计约52.3%；这是训练中的描述性指标，不能当作行业因果贡献。

六组结束后，按预先约定选择原成本最高和两档较低年化最高的模型；两种口径都指向31叶600轮，去重后只对这一模型做五项独立交互。

达到目标后冻结50.4756%方案，邻域只用于报告敏感性，不再据其最高值重选冻结策略。邻域结果与验证记录见下文。

## 可复现输入与证据边界

新增`nonlinear_scoring.py`严格限定输入列。`boosted_tree_scoring.py`读取可移植JSON，使用NumPy逐树推理，无需生产环境安装scikit-learn或执行pickle。树节点、缺失值走向、阈值、特征顺序和基准预测均保存；拒绝未知结构、类别分裂、循环、错误列名和无穷输入。输出是预测净收益，高分优先，不是胜率概率。

研究输入与逐笔账本存于`~/.cache/tushare-hub/`下各`stockops-return50-*-20261019`目录。非线性目录保存协议、特征轴、模型元信息、完整树JSON、便携模型、候选评分和两档账户；integration目录保存事前组合协议、冻结选择、全部交互和邻域。旧五年基础面板及分红来源保持不变。

独立复核逐元素核对了520690行候选轴、36列输入和490655行训练标签，未发现未来目标或证券身份进入特征。原始个股20期收益按有效行情数计算，行业20日动量按市场日计算，有4行相对收益窗口不完全同长；这是继承的窗口口径问题，本轮未改写。原数据历史资格和行业数据沿用既有认证范围，不因本轮模型改进而升级数据认证声明。

日线回放使用开盘价加固定滑点。收到卖出回报后能否仍按该开盘代理价完成预备买单、资金增长后的实际开盘容量，尚未通过分钟级或实际订单验证。

组合首个账户的末端重构差额为1.02445e-8元，约548万元净值的11个浮点间距。原审计与零比较采用固定1e-8元阈值，因而误报。修正仅使重构差额容差按64个末端净值浮点间距缩放，下限1e-8元、上限1e-6元；一分钱差额仍拒绝。保留原始差额，未改交易、费用、价格或净值；修复后原账户CSV和metrics逐字节相同。

## 软件验证与独立核账

本轮120个正式账户全部通过主线程CSV核账，保存的最大货币重构残差约1.58e-8元。另一agent独立复算冻结两账户的每日净值、年度收益、胜率、单笔收益和真实入场间隔，并逐日确认信号最长间隔为1日。两账户现金均未为负，最大暴露分别为99.9696%和99.9421%。独立核账仍不等于从完整未平仓权益重新建立全部账户，保留既有审计边界。

六份便携模型各对520690行候选推理，与原scikit-learn预测逐位相同，最大差额均为0。最终最佳模型再次以冻结代码核验。228项相关软件测试通过；本轮涉及的三个源码模块合计263条语句覆盖率100%，Ruff格式、静态检查及Mypy通过。

复现可使用非线性缓存的`run.py`和已冻结`protocol.json`重新训练，临时训练环境使用scikit-learn 1.9.1；推理使用`models/hgb_leaves31_rounds600-portable.json`。组合回放入口为integration目录的`run.py`，参数文件为`integration-cases.json`，冻结选择位于`frozen-target-selection.json`。重跑须使用新的输出目录，避免已有账户与新模型混用。全部120账户的指标与审计汇总分别在`all-results.json`、`all-audits.json`，独立复核位于`stockops-return50-adversary-audit-20261019/accounts-audit.json`。
