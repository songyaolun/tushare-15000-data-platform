# 运行手册

使用 Python 3.11 或更新版本。依赖和所有 Python 命令通过 uv 执行。

```bash
uv sync --all-extras --dev
uv run tushare-hub --help
uv run ruff check .
uv run mypy
uv run pytest --cov=tushare_entitlement_hub --cov-report=term-missing --cov-fail-under=100
bash scripts/demo.sh
```

## 目录与覆盖债务

```bash
uv run tushare-hub --db data/hub.duckdb catalog sync --fixture fixtures/catalog/official
uv run tushare-hub --db data/hub.duckdb catalog list --lifecycle unclassified
uv run tushare-hub --db data/hub.duckdb coverage report --as-of 2024-01-03
uv run tushare-hub --db data/hub.duckdb products build --as-of 2024-01-03 --output data/products
```

完整官方快照会如实产生文档不确定性和未运行债务，`coverage report --gate` 因此返回非零。该结果用于阻止虚假的全覆盖声明。精简演示目录只用于演示代表接口，不是官方全量目录。

公开文档更新使用 `catalog sync --online` 显式执行。它只访问文档站，不调用数据 API。抓取失败会写入清单并产生复核债务，新接口默认未归类。

## 计划与恢复

```bash
uv run tushare-hub --db data/demo.duckdb catalog sync --fixture fixtures/demo/catalog
uv run tushare-hub --db data/demo.duckdb ingest plan daily 2024-01-02 2024-01-02 --observed-at 2024-01-03T00:00:00Z --output data/daily.plan.json
uv run tushare-hub --db data/demo.duckdb ingest run data/daily.plan.json --fixture fixtures/demo/responses.json --references fixtures/demo/references.json --observed-at 2024-01-03T00:00:00Z
```

失败后保留计划和原始层，使用同一个计划重跑即可恢复。新的回看任务使用 `--mode lookback`；历史回填使用 `backfill plan`。增量和回看会从现有水位减去政策回看窗口。水位按接口、日期维度和证据来源独立管理。

证券分片使用 `--parameters` 提供 JSON，包含 `ts_code` 或 `ts_codes` 列表。`trade_dates` 可提供交易日集合，禁止以简单工作日判断代替真实交易日历。未提供交易日时按自然日规划，空响应会阻止完成，避免把休市或失败悄悄计作完整。

财务 VIP 按 `period` 指定报告期，多季度区间自动拆到各季度末；月度宏观使用 start_m/end_m，季度使用 start_q/end_q。探活样本参数与全量采集参数分开，计划不会自动把示例证券当作完整证券范围。事件任务仍需用户给定明确边界与必要参数。

## 品质与产品

`quality audit` 可以传入日历、停牌和复权因子参考。缺少参考返回 not_checked；字段缺失、无效价格、无解释缺口等返回错误。历史修订需要按观察版本审计，不能把不同时点的同业务主键直接当作源接口重复。

`products build` 输出十类 Markdown 与 JSON，并可通过 `--parquet` 导出标准层。没有输入时生成缺数据说明，不输出市场判断。完整离线示例使用 `scripts/demo.sh`，其输出目录可通过 TUSHARE_DEMO_DIR 指定。

## 运行限制

当前是单机单写者实现，不提供分布式任务队列、真实账户权限保证或持续运行的调度服务。限速器共享范围是当前进程；多进程采集同一账户需要外部统一限速。真实接口的分页支持、单位、披露时点和权限冲突必须先核验，不能用离线样本代替。
