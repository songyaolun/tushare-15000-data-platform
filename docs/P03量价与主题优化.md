# P03 全样本策略优化

本文结果属于全市场逐信号研究。后续加入资金约束后，原放量反转组合的模型净值年化为4.35%、胜率61.20%；市场阶段切换没有同时改善收益并满足胜率、频率要求。账户收益与Alpha判断以[市场阶段与组合归因](P03市场阶段与组合归因.md)为准，不能用本文逐笔均值和机械周转估算替代账户净值。

五年全样本已找到同时满足“费后胜率至少 65%”和“全市场实际入场最长间隔不超过十个交易日”的策略。四个候选均完成独立逐笔复算，买卖日期、收益、交易状态和频率与参数搜索一致。

当前首选是**放量反转＋行业群动，止盈 4%、止损 10%、第 20 个持有交易日收盘发出到期退出指令**。它在首轮达标候选中平均单笔收益最高，胜率为 **67.05%**；延长持有期限的版本胜率为 **70.79%**，平均收益相近，但平均亏损更大。

| 版本 | 止盈／止损／到期 | 已退出交易 | 费后胜率 | 平均单笔收益 | 盈利因子 | 最长入场间隔 |
|---|---|---:|---:|---:|---:|---:|
| 均值优先，当前首选 | 4.0%／10%／20日 | 50,230 | 67.05% | 1.07% | 1.360 | 7日 |
| 胜率更高 | 4.0%／10%／60日 | 49,009 | 70.79% | 1.06% | 1.315 | 7日 |
| 止损更紧 | 2.5%／6%／20日 | 52,163 | 67.80% | 0.77% | 1.331 | 7日 |

另一个经过完整复算的方案是 **BOLL 下轨重入＋行业群动**，止盈 1.5%、止损 10%、到期六十日，86,045 笔已退出交易的胜率达到 **80.18%**，平均单笔收益为 **0.46%**，盈利因子为 **1.207**，最长入场间隔九日。它是首轮满足频率条件的最高胜率版本。平均盈利为 3.34%、平均亏损为 11.20%，较小的止盈幅度牺牲了单笔收益，因此单独列作高胜率选择。359 笔未平仓全部计亏后，胜率仍为 79.84%。

该方案要求前一交易日收盘低于当时的 BOLL 下轨，当日收盘回到当日下轨之上且比前一交易日上涨，再通过相同的行业群动条件。BOLL 使用二十日均值及两倍总体标准差；买单到期、成交和费用口径与首选版本一致。

首选版本共确认 57,723 个信号，实际入场分布在 944 个交易日。33,677 笔盈利，收益中位数为 4.06%，平均盈利 6.02%、平均亏损 9.01%，平均持有 9.06 个市场交易日。另有 309 笔未平仓、27 笔买单到期、38 笔样本末未成交、7,119 个重叠信号跳过。未平仓全部按亏损计入后，胜率仍为 66.64%。

“已达标”指本次全样本优化结果。五年全部用于选参数，没有保留验证集或测试集，也没有据此声称未来仍有同样胜率。原文基线为 29.41%，但两轮证券范围和交易规则不同，不能把差值全部归因于某一个指标。

## 首选策略的选股与买卖规则

在收盘后检查以下条件，全部满足才发出信号：

- 股价相对五根有效日线之前仍然下跌，当日收盘高于前一市场交易日收盘。
- 当日成交额是此前二十根有效日线成交额中位数的 1.2 至 3 倍。
- 收盘位于当日最高价与最低价区间的上方 30% 内。
- KDJ 的 J 值低于 80，避免反弹时摆动指标已经过热。
- 剔除本股后，同一历史行业至少五只有效同业，行情覆盖率至少 90%，上涨占比至少 60%，等权涨幅为正。

信号后等待三个市场交易日内的首个合格开盘买入，买单逾期取消。买入后，以实际买入价和复权因子计算涨跌幅：收盘达到 4% 止盈、跌至 −10% 止损，或达到第二十个持有交易日，发出退出指令，在之后首个可成交开盘卖出。同股持仓期间不叠加仓位。

这套条件选择的是“前期回落后，放量收强，并有同行业股票同步回升”的买点。KDJ 负责约束位置，行业群动确认回升并非只有本股。BOLL 已作为独立候选充分比较，本轮最优条件未要求额外叠加 BOLL。

## 热门概念补采后的结论

全量搜索共完成 **4,320 组**不同参数组合，501 组同时达到胜率和频率要求，其中 310 组平均费后收益为正。行业与市场背景占 2,700 组，概念背景追加 1,620 组；全部试验已保留在合并清单中。

P02 在本轮落实为历史行业成员、活跃强度和剔除本股的群动统计；热门概念则重建每日目录及当日成员。补采覆盖 439 个交易日，原始行业数据为 94 个文件，概念数据及完成清单为 2,635 个文件。正式补采代码已通过完全离线的缓存重放，生成的概念选择清单与首次采集完全一致。

在放量反转、4% 止盈、10% 止损、六十日到期的相同条件下，结果如下：

| 主题背景 | 胜率 | 平均费后收益 | 最长入场间隔 |
|---|---:|---:|---:|
| 行业活跃且群动 | 68.74% | 0.78% | 12日 |
| 行业活跃群动，或热门概念群动 | 68.68% | 0.75% | 9日 |
| 仅行业群动 | 70.79% | 1.06% | 7日 |

加入热门概念减少了等待信号的空窗，但没有提高平均收益。完整样本的首选因此保留行业群动，不再强制要求热门行业或概念。

纯概念条件在 2024 年 12 月 20 日之前没有历史成员可用，五年起点至首次入场的空窗约 774 个交易日，不能满足五年频率目标。它的收益只能解释为所覆盖期间的结果。以放量反转、4%／10%／二十日参数为例，纯热门概念群动有 699 笔已退出交易，胜率 64.09%，平均收益 0.46%；不能将这一较短窗口与全五年的行业结果视为同区间因果检验。

## 统一买卖口径

信号使用当日及此前信息。行业日线通常盘后更新，因此研究决策按次日开盘前形成，不能解释为当日收盘即可取得所有供应商指标。历史补采按供应商当前提供的历史版本重建，始终保留 `historical_pit_certified=false`。

收盘条件成立后，买单等待随后三个市场交易日内的首个合格开盘，第三日收盘到期。停牌不延长期限，开盘涨停或缺少有效限价拒绝买入。同一股票在同一策略下只保留一笔持仓或待成交订单。

止盈、止损和持有期限都在收盘观察，触发后在随后首个可成交开盘卖出。遵守 T＋1，开盘跌停不能卖出。阈值不保证实际成交收益，跳空和停牌可能放大亏损。

费用沿用修正版基线：双边滑点各五个基点、佣金各三个基点，印花税按 2023 年 8 月 28 日前后分别采用千分之一和万分之五。结果是供应商复权因子下的费后研究收益估计，没有重建完整分红现金账本、最低佣金、过户费或资金受限的组合净值。

## 第一轮搜索范围

第一轮包含十二类选股条件：MACD 穿越、趋势回踩、趋势内 BOLL 恢复、KDJ 恢复、超跌恢复、重新进入 BOLL 下轨、区间低位、放量突破、放量反转、深度回调、缩量回调、KDJ 低位金叉。每类分别叠加无背景条件、市场上涨广度、行业活跃、行业群动、行业活跃且群动五种背景。

每种入场条件比较四十五组退出参数：止盈为 1.5%、2.5%、4%、6%、8%，止损为 3%、6%、10%，持有上限为二十、四十、六十个市场交易日。共 2,700 组尝试，全部保留，不只公布赢家。参数空间并不代表这些参数已经有效。

KDJ 使用九日 RSV，K、D 按三分之一递推，初值均为五十，J＝3K－2D。零九日振幅保持未知并重置递推。BOLL 使用二十日均值和两倍总体标准差。量价比较使用当日成交额与此前二十日中位数之比，参考窗口不含当日。均线距离按 ATR14 衡量，所有窗口使用同一固定首因子锚定的复权价格。

## 历史行业和概念怎样重建

申万一级行业补采全部三十一个行业的当前成员、已退出成员及 2020 年以来日线。成员使用纳入日包含、退出日不包含的区间，缺日期或同日跨行业冲突时不分配行业。行业分类采用供应商当前可取的 SW2021 体系，可能存在历史重述，因此不能声称复原了当年不可变的行业目录。

行业活跃条件使用五日行业价格强度的当日行业间分位至少 0.8、成交额不低于此前二十日中位数、指数站上二十日均线。这是交易活跃代理，不是供应商热搜排名。

行业群动剔除候选股自身，要求至少五只有效同业、行情覆盖率至少 90%、上涨占比至少 60%、同业等权收益为正。另保存站上二十日均线占比、突破二十日高点占比和涨停广度。热门与群动联合条件必须在同一行业满足，不把不同主题各自通过的条件拼接。

东财概念逐日成员从 2024 年 12 月 20 日开始提供。补采该日起的每日概念目录，并按当日涨幅与换手率的平均秩选择活跃前五概念，读取它们当日的历史成员。不能把当前热门概念或当前成员倒推五年。概念对照只能在其实际覆盖范围解释；不足五年的范围明确披露。

原数据包含退市证券，候选不按今天的上市名单缩池。第一轮量价搜索限定原行情中沪深证券，北交所因原五年报告已经发现历史交易身份和限价缺口单独排除并计数。

## 结果验收

费后收益严格大于零才计为胜；分母是已退出且收益可计算的交易。未退出、买单到期、尾端未成交和重叠信号分别统计。频率按实际入场日去重，检查最长间隔，并包含研究起点至首次入场、末次入场至研究终点的空窗。同一天大量信号不能掩盖数月无信号。

选优先检查 65% 胜率和十交易日间隔，然后比较平均收益与盈利因子。年度结果按确认年汇总，仍使用全程连续持仓，不把跨年交易人为重开。最终候选必须用原有独立成交状态机重新逐笔计算买入日、卖出日和费后收益，再报告准确的中位数、平均盈利／平均亏损和未平仓规模。

本轮是全样本优化回测，不作未见样本外表现承诺。真实数据、完整搜索日志和交易记录保存在私有缓存；仓库只提交代码、确定性测试和说明。

## 复现命令

在本分支 worktree 中执行。先准备原五年已核验的 `history.duckdb` 和交易日历文件。下列目录变量指向用户自己的私有缓存，凭据文件只由既有凭据读取函数访问。

```bash
RESEARCH_ROOT="$HOME/.cache/tushare-hub/p03-optimization-20261018"
uv run tushare-hub strategy-optimize collect-history \
  /path/to/private/tushare.env /path/to/trading_dates.json "$RESEARCH_ROOT" --live
uv run tushare-hub strategy-optimize prepare \
  /path/to/history.duckdb "$RESEARCH_ROOT/sector-history" "$RESEARCH_ROOT/features"
uv run --with numba tushare-hub strategy-optimize search \
  "$RESEARCH_ROOT/features" "$RESEARCH_ROOT/search-fast-full" --accelerate
uv run tushare-hub strategy-optimize attach-concepts \
  "$RESEARCH_ROOT/features" "$RESEARCH_ROOT/concept-history" "$RESEARCH_ROOT/features-concepts"
uv run --with numba tushare-hub strategy-optimize search \
  "$RESEARCH_ROOT/features-concepts" "$RESEARCH_ROOT/search-concepts" --accelerate --concepts-only
```

搜索输出目录必须是新目录。首次补采与后续缓存复用共用入口，联网必须显式传入 `--live`。概念搜索另加活跃概念、活跃概念群动、行业活跃群动或概念群动三类背景，共增加 1,620 组试验。纯概念条件在历史缺口期间不产生信号，因此不能单独满足五年最长十日间隔；行业或概念的联合条件可以贯穿五年。

`--accelerate` 仅编译累计内核，不改变入场、退出或去重规则。Numba 通过 `uv run --with numba` 使用，不增加生产必装依赖。同样十只股票、2,700 组试验，预热后的计时为 1.29 秒，原路径为 3.78 至 3.82 秒；逐字段结果误差小于十的负十次方。这是本机计时，完整搜索耗时以实际日志为准。

选定参数后运行 `strategy-optimize verify FEATURES OUTPUT FAMILY CONTEXT TAKE_PROFIT STOP_LOSS HOLDING_SESSIONS`，由独立逐笔引擎核对所有买卖日期和收益，输出完整 `trades.csv` 及 `verified.json`。未平仓逐笔记录末次有效报价、报价陈旧天数和浮盈亏，另给出未平仓全部计亏时的胜率。

本分支依赖前置 [MR 5](https://code.byted.org/songyaolun/tushare-15000-data-platform/merge_requests/5) 的历史面板与成交模拟基础。面向 main 的差异包含前置变更；本轮新增实现集中在 `strategy_optimization`，原成交引擎只增加可选订单到期和止盈参数，默认行为保持原协议。

正式研究窗口包含 1,212 个市场交易日，技术指标另用此前历史预热。基础数据集覆盖 5,451 只沪深证券，另有 356 只北交所证券因原历史身份与限价缺口排除。行业原始补采保存 94 个分区文件，成员重建发现 380 条无效或研究范围外记录，冲突证券日为零。
