# 安全说明

本项目开发与默认测试不读取、索取或使用真实 Tushare Token，不调用真实数据接口。演示数据是明确标注的合成样本。

生产传输只接受 https://api.tushare.pro，禁用重定向和环境代理继承。live 必须显式开启，且与 fixture 互斥。Token 由调用方提供的延迟函数在最终发送步骤取得，不进入日志、异常、请求标识、缓存键、原始层或产品清单。CLI 仅在显式 live 请求最后一步使用不回显的交互输入，不自动读取环境变量。

凭据字段、嵌套凭据字段、字段列表中的凭据名和文本凭据赋值会在持久化前被拒绝。传输层额外检查服务端是否回显当前凭据值。错误分类使用有限错误码，不返回原始服务端消息或底层异常链。

公开文档同步仅访问 Tushare 官方 HTTPS 文档路径，不携带账户凭据。快照去除登录界面和追踪脚本，公开示例中的凭据实参替换为占位符，并记录净化后的哈希。该哈希证明仓库快照内容一致，不代表官网网页字节级签名。

默认测试通过网络阻断 fixture 防止意外联网；HTTP 行为使用 httpx.MockTransport 和 FakeTransport。CI 不配置账户凭据、真实定时任务或部署权限。控制面指标按接口和有限状态聚合，不使用 Token、证券代码或完整请求参数作为指标标签。

本地原始层仍含证券代码和业务参数，属于审计数据，应由使用者按照自己的数据保留策略管理。不要将真实账户原始响应或本地 DuckDB 提交到 Git。项目提供忽略规则，但提交前仍需检查差异。
