# P03涨停接力与量价托探索

研究日期：2026年10月18日。承接[行业层级与回踩验证](P03行业层级与回踩验证.md)，本轮转向独立于原放量反转和行业初期的入场来源。

12个新配置全部亏损，没有达到胜率至少65%、实际入场最长间隔不超过10个交易日且账户正收益的目标。原行业初期追价版精确复现，年化11.91%、胜率47.43%。新方案中量托较长持有版亏损相对最少，年化仍为−4.95%。不能将这些规则替换现有基准。

本轮没有分钟或逐笔成交、封单排队数据，所以涨停组是“收盘确认后次日接力”，真正的盘中打板仍未验证。以下失败结论只适用于本轮固定的事件定义、排序、买卖点与执行方式，不能推广到所有打板、量托或价托策略。

量托较长版2024、2025年盈利，2022、2023和2026部分年度亏损。它有一定行情依赖，但不能看完年份再指定“哪些年份启用”，本轮没有验证可提前识别的市场阶段切换规则。

机会互补性已经出现。原基准2026年5月11日至7月30日的58个收盘日无候选，首板、二板、炸板和量托在其中58日都有符合共同资格的候选，价托有52日，双托有33日。量托较长版还有802个实际买入日落在原基准没有买入的日期。它们补充了原策略没有覆盖的时间，但负收益意味着目前无法据此认定有益分散。没有达到预定追加条件，本轮未运行任何组合。

量托较长版2393笔平仓中，有1746笔因收盘跌回MA20而退出，平均净收益−2.24%；因止盈退出的188笔平均收益25.37%。这说明策略能捕获部分上涨，却被大量未延续的形态和退出损失拖累。这是对当前成交结果的描述，不能据此认定关闭MA20退出必然改善收益；关闭后可能扩大亏损。

涨停组也不只是输在低开。首板较长版剔除开盘跌停及其余低开超过5%的交易后，剩余2449笔平均仍亏损0.67%。本轮只设置了3%高开上限，没有设置低开下限，允许在跌停开盘买入；这沿用了现有日线开盘成交假设，但不等价于“次日强势确认”。该差异需要保留，不能把这一轮称为完整的强势接力系统。

最差首板交易来自原始面板中的300029.SZ：2026年4月28日在跌停开盘买入，次日继续跌停，之后长期缺行情，到6月18日才有可卖开盘，较长版该笔亏损94.25%。该交易遵循了T+1与限板约束，但止损阈值无法保证有可成交的卖点。源数据的历史风险标记及缺行情原因尚未完整认证，本轮也没有补齐历史ST、退市风险公告。这一诊断只确认了面板中的价格与成交路径，尚未确认缺行情背后的公司事件；筛选资格也不能用今天的证券状态回填。

研究区间为2021年10月18日至2026年10月16日，共1212个交易日，覆盖原冻结面板中的5451只沪深证券，指标从2020年预热。仍用100万元本金、无杠杆、90%总仓位上限、单股5%及一级行业25%上限。日线成交延续原手续费、滑点、整手、涨跌停和分红规则。

首板要求此前十个连续有效市场日没有封板，今日收盘等于官方涨停价且最低价低于涨停价。二板要求昨日、今日连续封板，再前一日未封板，今日也须有低于涨停价的成交。炸板修复要求今日最高价触及涨停、收盘未封住但离涨停不超过3%。共同要求成交额至少为此前20个有效观察日中位数的1.2倍、换手率在1%至30%、收盘位于当日振幅的上方40%且当日复权收益为正。此前11个市场日的行情及官方限价必须完整，限价带必须大于7%。不按固定10%涨幅推断涨停，沿用各证券当天的官方价格上下限。

涨停事件三类信号各有两种退出。短持有版采用8%收盘止盈、5%收盘止损和最多3个市场日持有；较长持有版为15%、8%、10日，并增加8%的收盘峰值跟踪退出。所有订单仅允许次市场日开盘成交，高开超过信号日复权收盘3%时取消，开盘涨停不能买入。错过次日后，旧事件订单到期；若之后另有新事件，则重新计算。

价托使用复权收盘价的5、10、20日均线；量托使用真实成交量的同周期均线。定义为十个市场日内，5日线先后上穿10日线、20日线，最后10日线上穿20日线，三次交叉可以同日，顺序不能倒置。最后一叉当日发出形态事件，并要求当前5日线高于10日线、10日线高于20日线，20日线不低于三日前。量价双托要求两种事件都在最近五日内出现，其中至少一种在当天完成，且两组均线仍维持多头排列。

三种托都要求34个连续有效市场日且复权因子不变，避免停牌和除权变化制造交叉。当天收盘必须高于20日价格均线、追离不超过10%，当日收益为正、收盘位置至少60%。排名偏好收盘较强且离均线较近的证券。短持有版为8%收盘止盈、5%收盘止损、最多10日；较长版为20%、8%、30日，并增加8%的收盘跟踪退出。两版都在收盘跌破20日均线时发出退出指令，买入最多等候三个市场日、追价上限2%。量托描述成交量形态，不代表已经确认资金净流入。

各退出阈值均在收盘确认，等下一个合格开盘执行，实际损失可能超过止损阈值。全程保留T+1，买入当天不能卖出。新策略不要求原放量反转或行业初期信号，但实际候选仍须通过原共同资格，包括已知行业、Beta与市值、最低成交额及限价带。没有把今天的热门概念回填到历史。

实验开始前固定13个独立账户：现有行业初期追价版1个，涨停事件6个，量价托6个。每个新组只从年化为正且最大回撤不超过20%的配置中选择最高年化者，再与基准各分配50万元组合，最多追加两个组合、四次子账户回放。组合期间不转移现金、不重新平衡子账户资金比例，不能把两条100万元净值曲线直接平均当作真实组合结果。所有尝试均列入报告，没有追加阈值搜索。

全部五年用于优化，没有保留金融样本验证集或测试集。软件测试检查计算、资金账本与时间因果性。全样本反复选优不能证明样本外有效性，供应商历史行业重构、历史ST及公司行动覆盖的既有限制仍在。

40份研究及相关价格结构源码在回放前冻结，结束后摘要一致。原基准全部指标数值一致，四份CSV逐字节复现；配置清单新增了订单有效期字段，旧配置默认仍为三个交易日。首板、二板和炸板的所有已平仓交易均核对为信号后的次市场日买入。

独立CSV复算通过13个配置、36462笔平仓，核对了逐日收益、年度收益、胜率、空窗及资金恒等式。另逐笔核对已平仓交易的开盘价、滑点、整手、手续费和T+1。原基准期末无持仓，因此费用能够全部核平；12个新配置期末仍有7至14笔持仓，输出缺少完整未平仓交易明细，费用审计只核对已平仓子集，不宣称全部费用已经独立核平。

首板短版、二板短版、二板较长版分别有3737元、11310元、10686元陈旧估值。按原规则它们仍计入净值；将其归零只会使结果更差，不能消除本轮亏损。其他配置陈旧估值为零，期末正常持仓仍按原规则估值，没有强制虚构末日平仓。

1048项研究测试与93项关联测试通过，共1141项；两个研究包2615条语句覆盖率100%，Ruff与164个源文件的严格mypy通过。没有重跑全仓测试。新增逻辑拆分为市场日窗口、涨停事件、量价托三个独立模块，复用原资金账本，仅增加可选的一至三日订单有效期。

后续若继续研究，涨停方向首先需要能按历史时点使用的风险标记与次日强弱条件；真正打板还需要分钟或逐笔成交数据。量价托方向可检验“只买形成后守位成功的形态”和不同退出规则，但这些都未在本轮验证。本轮没有通过事后挑选年份或删除亏损交易来制造新结果。
