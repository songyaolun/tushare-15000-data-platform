# 止盈幅度实验结果

固定31叶12800轮评分、2.5%预算与Top10，4.5%止盈主账户正常／双成本CAGR为210.73%／206.26%。
3%为197.21%／192.13%，6%为201.82%／197.03%，9%为184.56%／180.33%，均未改善，主目标仍未达到250%。
本轮是五年样本内研究，分钟成交容量和独立泛化仍未认证。

本轮保留4.5%。主账户正常成本下，止盈3%／4.5%／6%／9%的平均敞口为
49.65%／51.10%／54.98%／60.47%；6%和9%费用下降，但收益仍低于4.5%。
3%触发止盈4117次，高于4.5%的3433次，较频繁退出也未改善五年收益。
6%在2024、2025年较强，仍不足以弥补早期差距；不从个别年度挑选赢家。

此前31叶模型从6400增至12800轮，在5%预算下主账户正常CAGR从176.22%升至199.48%。
下一轮保留本轮最优交易参数，预登记31叶25600与51200轮，并以12800轮为直接对照，
检验拟合容量增加后受约束收益是否继续改善。保留47列、原标签与全部失败结果；
增加训练轮数仍是样本内拟合，不能据此推断未来收益。
