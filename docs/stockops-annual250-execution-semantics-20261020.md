# 开盘竞价字段仍需供应商确认

沪深交易规则都明确：单次集合竞价的所有交易以同一价格成交。Tushare的
`stk_auction_o`公开样例却有不同的开盘价、收盘价和最低价，且没有日内时间戳。这不足以断言数据错误，
但不能把它直接当作9:25最终撮合数据。当前16420个需求证券日的市场覆盖仍为0，执行容量
仍未认证。本轮只读取公开规则和已冻结文档，没有调用行情API、申请权限或发送消息。

Top15账本及参数保持冻结。100万元原范围正常成本日历CAGR为253.4681%，双成本为
249.9240%，仍是样本内结果；保留12万元主板对照。主口径为2021-10-18至2026-10-16，
1824天、365.25天年基准。本文没有提高收益，也没有取得真实成交证明。

## 交易规则能确认什么

本轮读取沪深2026版正文和深交所2023版。2026版正文均宣布自2026-07-06施行。
上交所通知页面的状态栏仍写“尚未施行”，与通知正文及规则11.9冲突，原网页已保留；
这里记录正式正文宣布的日期，不以网页状态栏替代正文，也不宣称已完成五年历史PIT认证。
上交所两条2023版候选链接均返回404，本轮没有取得该旧版正文。深交所2023版只作历史
对照，不能填补上交所旧版、2021年至2023年规则及各板块例外的证据缺口。

| 机制 | 条文依据 | 对执行研究的限制 |
|---|---|---|
| 开盘集合竞价为9:15至9:25，连续竞价从9:30开始 | 沪2026版2.4.2；深2026版2.3.2 | “9:30集合竞价”标签的归档含义需供应商解释 |
| 9:20至9:25不接受撤单；申报先后按交易主机接受时间确定 | 沪3.3.1、3.5.1；深3.3.1、3.4.2 | 分钟汇总无法证明本策略的排队位置或申报已有效 |
| 集合竞价所有交易使用同一成交价 | 沪3.5.2；深3.4.3 | 若字段仅覆盖一次最终撮合，OHLC应对应同一价格；虚拟序列或跨时段汇总须另作解释 |
| 沪深在多个候选成交价之间的选择规则不同 | 沪3.5.2；深3.4.3 | 上海进一步取最小未成交量、仍相等取中间价；深圳比较累计申报数量之差，再按前收盘价或最近成交价选取，不得共用未经核实的重放规则 |
| 集合竞价未能形成开盘价时，由连续竞价产生 | 沪4.1.1、4.1.2；深4.2.1、4.2.2 | 日线open相同不能证明9:25成交；必须区分没有集合成交和缺失记录 |
| 竞价参考价、匹配量是揭示时点的虚拟成交结果 | 沪5.2.1、11.5；深10.4 | 虚拟匹配量不能当最终成交量，更不能把多次快照相加 |

深交所2023版3.4.3、4.2.2及定义条款也包含统一成交价、开盘价回退和虚拟匹配量。
这只是所读条文的对照，不证明全部历史规则未变化。上交所2026版暂缓附件涉及3.6节
部分大宗交易内容，没有列入上表引用的开盘条款；未把暂缓的大宗安排当作已实施。

## 最小验证协议

本协议只登记后续步骤，没有执行新行情请求。当前阶段可完成公开说明对照、需求文件哈希
核对和空证据的失败关闭测试；后续在线步骤须取得对应准入，仍沿用现有HTTPS transport、
RawStore及私有认证入口。供应商沟通、开权限或付款均不包含在当前授权中。

先把Q01至Q08答复存成带版本的字段契约。未知项逐一保留，不能用交易所时间表填成供应商
已确认时间戳。预登记探测样本从冻结需求中按日期、代码排序选择，不看后续收益；至少覆盖
沪市主板、科创板、深市主板、创业板及规则版本区间。另列供应商公开样例用于解释Q02，
不得把这些额外样例计入16420需求的覆盖。

每个样本先请求完整证券日，再用相邻且端点重合的小窗口检查边界；记录原响应、请求参数、
观察时间、合同指纹、字段及字节哈希。小窗口合并结果必须在定义清楚的端点规则下与全日
一致。没有独立带时间戳的最终竞价记录时，即使两接口数值相等，仍不能确认9:25语义。

另选独立状态证据明确的全天停牌、临停／复牌、无集合成交、零成交分钟及除权日，检查
Q03至Q06。候选需求中没有该类时登记“场景未覆盖”，不能制造样本或删去检查。无集合
成交必须靠独立事件证据区分，不能从接口空行反推。规则版本交界也按实际交易日选择。

首次探测每个接口仅开放已准入的样本；权限拒绝立即停止该接口，字段未知或冲突阻止扩大
采集。截断、重复冲突、错日、缺行和零量分别报告。速率遵循账号实际限制，次数在运行前
登记；不把文档最高频率当当前额度，不使用未声明的offset参数。

样本语义通过后才执行原32840条计划请求，最终仍按全部16420证券日验收。优先级0为
4286日，优先级1为12134日；成交之外的1126日继续保留。市场数据完整性、独立状态、
当前权限、历史PIT和执行容量分别报告，任何一项通过不替代其他项。

容量重放前还须冻结可成交价、下单延迟、窗口参与率和部分成交规则。单账户同证券同窗口
按总请求股数核对，不能把八个互斥账户的订单叠加；保留开盘现金约束和原历史限额。
最终市场量只用于事后执行审计，不能倒推信号预算或未来NAV。缺队列和盘口时报告
“未反驳／已反驳／未能判断”，不能把非零成交量当作成交保证。
