# 跨市场与融资研究

这三个产品把已适配、可追溯的来源数据加工为商品压力、跨市场比较和融资风险观察。实现覆盖消费矩阵中 P09 的 19 个接口、P10 的 26 个接口及 P11 的 14 个接口。覆盖表示每个接口有明确的字段选择、加工职责和离线回归，不表示正式数据已完成 observed 验收。

| 产品 | 公开入口 | 产品标识 |
| --- | --- | --- |
| 商品传导 | `build_commodities(inputs)` | `commodity_transmission/v1` |
| 跨市场传导 | `build_international(inputs)` | `international_transmission/v1` |
| 融资尾部风险 | `build_financing(inputs)` | `financing_tail_risk/v1` |

入口接收 `ResearchInputs`，返回 `tuple[ResearchResult, ...]`。每个结果复用公共决策信封、指标与证据契约。同一实体可以有不同来源或细分范围的结果，稳定身份使用包含 `feature_profile` 的 `result_id`。产品不生成交易指令。

## 指标先通过事实和时间检查

计算只读取 `ResearchRow.numeric` 中的 `TypedFact`，不把原始文本直接转为连续数值。事实必须有单位证书，质量为 `verified`，没有拒绝原因，并与行的实体、字段、来源和可见时间一致。

金额和价格必须有币种。共享读取函数保留 USD、HKD 等已认证本币数值，输出单位带币种标记；它不修改旧 `ResearchRow.number` 的人民币限制，也不做隐式换汇。同一个单位名称下的 USD 与 HKD 不能相减或相除。

比例和差值要求同单位、同量纲、同币种及同业务日。比例分母必须为正，结果必须有限。利率期限差进一步限定为 `ratio` 或 `rate` 量纲，不能把金额型 `close` 当作回购利率。单位为 `ratio` 时，0.03 减 0.02 得 0.01；展示必须沿用认证单位，不能自行追加百分比换算。

未来数据和隔离记录逐行排除，计入拒绝数量。只有目录或当前快照型接口可以在业务日期缺失时使用观察日期，并保留 `metadata_snapshot_observed_only`。这不会赋予历史时点认证。实时港股来源没有经过认证的行情时间戳，因此当前实现不生成其收益率，也不回填历史日线。

来源内身份、观察后目录、部分消费字段缺失和已排除行的审计注记保留在 `scope_annotations`，由各指标所需事实决定能否计算。缺少时区时可以做当前来源内观察；跨来源比较仍要求双方有时区证据。容量、来源身份、未解决的版本冲突等硬失败继续阻断整组精确指标。

## P09 按品种规格和库存层次加工

| 来源 | 实际加工 |
| --- | --- |
| `fut_basic` | 检查品种、交易所、交割月、报价单位和交易规格完整度；为期限结构提供显式合约归组证据 |
| `fut_daily` | `settle / close - 1`；`oi / vol`；同规格近远月曲线 |
| `fut_daily_adj` | 连续序列 `settle / close - 1`；有主力映射时核对实际合约收盘价 |
| `fut_mapping` | 检查映射完整度；以 `mapping_ts_code` 和业务日定位唯一实际合约，不猜代码含义 |
| `fut_holding` | 分别计算会员多仓、空仓样本集中度，公式为各会员占比平方和 |
| `fut_inv_weekly` | `cur_total / pre_total - 1`，按交易所、仓库、品级、品种和单位分层 |
| `fut_rcpt_mat` | `cur_month / next_month`，比较本月与次月到期仓单 |
| `fut_wsr` | `vol_chg / vol`，按品种、仓库、品级、厂库属性和单位分层 |
| `fut_settle` | 多空保证金率差；同实体同日与 `fut_daily.settle` 核对差值 |
| `ft_limit` | `up_limit / down_limit - 1` 和已认证保证金要求 |
| `fut_trade_param` | 输出已认证的最小价位、限仓和涨跌幅约束 |
| `fut_trade_cal` | 解释最新可见交易日的开闭市枚举 |
| `fut_weekly_detail` | 周口径 `open_interest / vol`，保持周频范围 |
| `fut_weekly_monthly` | 按频率计算 `settle / close - 1`，作为重采样行情核对 |
| `fut_index_daily` | 保留来源内已认证商品指数变动，不用指数替代合约 |
| `sge_basic` | 检查贵金属现货交易方式、计价与交易单位及时段完整度 |
| `sge_daily` | `price_avg / close - 1` 和 `oi / vol`；有可比关系时计算现期价差 |
| `fina_mainbz` | 分部成本率及毛利率；与 VIP 同快照核对收入和成本 |
| `fina_mainbz_vip` | `bz_cost / bz_sales`，毛利率为 `1 - 成本率`；附已确认的商品暴露关系 |

期限结构按 `exchange`、`fut_code`、`quote_unit`、`trade_unit`、`per_unit` 和业务日分组，使用元数据中的交割月排序。远近月指标为 `远月结算价 / 近月结算价 - 1`。正值标为升水结构，负值标为贴水结构，零值标为平坦；交割月冲突、容量不足或数值不可比时，指标与结构标签都保持未知。当前不按缺失的具体交割日年化。

会员集中度仅描述已观察样本。混入合计行、重复会员、数量单位不同或缺值时不计算；不把会员多空集中解释为净看多。仓库、品级和厂库明细分别输出，避免把合计与明细相加。

普通与 VIP 主营数据只在实体、分部、币种和报告期一致时核对。收入不会跨两来源重复相加。企业商品关系只支持暴露证据，不估计价格敏感度，也不根据业务关键词生成受益股票名单。

## P10 保持市场、币种和会计范围

| 来源 | 实际加工 |
| --- | --- |
| `stock_company` | 公司主体与业务范围完整度；跨市场等价关系仍需显式证据 |
| `fx_obasic` | 货币对身份、报价商、分类和交易时段完整度 |
| `fx_daily` | 中间价为 `(bid_close + ask_close) / 2`；相对报价差为 `(ask_close - bid_close) / 中间价`，要求 `0 < bid ≤ ask` |
| `index_global`、`us_daily` | 各自市场、各实体的已认证来源内变动，分别读取 `pct_chg`、`pct_change` |
| `hk_basic`、`us_basic` | 保留各自生命周期、市场与币种相关元数据完整度，不按相同代码合并实体 |
| `hk_tradecal`、`us_tradecal` | 开闭市状态和当前日距上次交易日的日历间隔 |
| `rt_hk_k` | 保留当前观察的证据与时间戳缺口，收益率保持未知 |
| `hibor` | 十二月利率减隔夜利率 |
| `libor` | 同币种十二月减隔夜利率，明确标为已停止更新的历史基准 |
| `us_tbr` | 十三周减四周的贴现率差、等价收益率差分别计算 |
| `us_tltr` | `ltc - cmt`，命名为方法范围差，保持长期样本与固定期限口径差异 |
| `us_trltr` | 根据认证 `ltr_avg` 形成长期实际利率正负状态，不与固定十年点相减 |
| `us_trycr` | 三十年减五年实际利率差 |
| `us_tycr` | 十年减二年、十年减三月名义利率差 |
| `hk_income`、`us_income` | 同长表净利润除以收入 |
| `hk_balancesheet`、`us_balancesheet` | 同长表负债除以资产 |
| `hk_cashflow`、`us_cashflow` | 经营现金净流量绝对值占经营、投资、融资三类净流量绝对值之和的比例 |
| `hk_fina_indicator` | 毛利率减经营现金销售比，观察盈利与现金实现差异 |
| `us_fina_indicator` | 会计准则、币种、报告类型和财年文本完整度，不把月日文本补成年月日 |
| `stk_ah_comparison` | 只有已确认 A/H 配对且港股代码匹配有效别名，才使用认证的提供方溢价指标 |

同日十年名义收益率与十年实际收益率可生成差值代理。这个值包含风险和流动性溢价等因素，不命名为真实通胀预测。跨来源缺少时区、单位不同或数据日不同都会使该指标未知。

港美财务长表使用固定的精确指标名称映射，不做关键词或模糊匹配。美股长表按 `ind_type`、`report_type` 分组，再取最新报告期。重名指标、混币、所需指标缺失及非正分母均不计算。两市场结果不进入统一股票排名，也不通过公司名称推定会计口径一致。

交易日历接受数值 0、1，包括标准化后的 0.0、1.0，以及文本 `"0"`、`"1"`。布尔值、任意非零浮点和文本 `"1.0"` 不会隐式转换为开市。

## P11 分开融资、报价和实际成交

| 来源 | 实际加工 |
| --- | --- |
| `margin` | 净融资强度为 `(rzmre - rzche) / rzye`；融资余额占两融余额比例为 `rzye / rzrqye` |
| `slb_len` | 偿还压力为 `repay_amount / ob`；余额恒等式残差为 `cb - (ob + auc_amount + repo_amount - repay_amount)` |
| `repo_daily` | `close - weight`，两项都按融资利率解释，`close` 不能用作证券价格 |
| `shibor` | 一年减隔夜、一月减隔夜的资金期限差 |
| `shibor_quote` | 不同银行隔夜和一月双边报价分别计算样本极差 |
| `gz_index` | 广州样本长期利率减十日利率 |
| `wz_index` | 温州长期减一月利率、小微减综合利率，保持地方样本范围 |
| `bc_otcqt` | 同券、同剩余期限，每家银行只取最新有效时刻报价，再分别计算买卖收益率极差 |
| `bc_bestotcqt` | 最优买入收益率减最优卖出收益率，标注为报价观察 |
| `bond_blk`、`bond_blk_detail` | 各自来源的成交价格极差及最大单笔金额占比，汇总与明细不相加 |
| `opt_basic` | 合约类型、看涨看跌、执行方式、到期与乘数规格完整度 |
| `opt_daily` | 单合约 `oi / vol`；有明确标的关系时加工同到期期权组 |
| `vix_index` | 已认证的美国隐含波动变化，保留美国市场范围 |

债券报价不代表成交。银行报价时刻先解析为有效时间，同一银行同刻冲突会阻断精确离散度；不足两个可比银行样本时，不把离散度补成零。大宗汇总与明细分别输出，即使内容相同也不会共同进入一个成交额分母。

期权组要求明确标的、有效到期日、执行方式、期权类型和相同合约乘数。已过期或日期非法的合约不入组。成交 PCR 为同组看跌成交量之和除以看涨成交量之和，持仓 PCR 用持仓量独立计算。任一贡献量缺认证、为负、单位不一致或看涨分母不为正时，指标未知。PCR 描述尾部对冲活动，不生成方向预测。

## 关系必须明确且在截止前可见

| 关系类型 | 起点与终点 | 用途 |
| --- | --- | --- |
| `commodity_exposure` | 企业或证券实体 → 明确商品实体 | 为主营分部结果附商品暴露证据 |
| `spot_futures_comparable` | 现货实体 → 可比期货合约实体 | 同日同单位的 `期货收盘价 / 现货收盘价 - 1` |
| `option_underlying` | 期权合约实体 → 标的实体 | 划定同标的期权统计范围 |
| `ah_pair` | A 股实体 → 港股实体 | 验证 A/H 提供方溢价的实体对应 |

关系须为 `confirmed=True`，在分析截止前可见且当时有效。A/H 还要使用 `tushare_hk` 命名空间，在来源业务日期解析 `hk_code`，结果必须等于关系终点。跨来源的业务组键、同名公司和相同代码均不构成关系证明。

## 保留完整计数并限制结果体积

`Frame` 一次扫描来源，按实体和细分维度保留最新可见快照。同来源业务组下相同选定字段记为重复；字段不同时保留版本冲突，不随意挑第一条。跨 API 的业务组键互不去重。

每组记录观察行数、快照行数、重复数、拒绝数，以及覆盖全部输入身份和选定字段的摘要。字段证据最多采样八行，衍生结果补充的规格和关系引用最多保留六十四条，并记录完整补充引用数量及摘要。抽样不用于计算分母，也不伪装成完整观察数量。

达到配置容量上限时，整组精确指标拒绝计算。单个结果超过 8 MiB 时返回带 `result_payload_capacity_exceeded` 的受阻结果。结果仍使用公共的未知值语义，缺值不会变成零，软注记也不会抵消硬门禁。

## 验证范围

专属测试使用合成 `ResearchInputs`，覆盖本币与外币、单位和时区缺口、显式关系、源内重复与跨源核对、到期和报价时间边界、零一日历枚举、健康与被拒绝行并存，以及容量和证据采样。

完整适配链由统一离线验收通过合成参考库运行。正式数据的可用范围、来源数量及 observed 状态必须以相应实际运行产物为准，不能由本说明或合成测试结果推定。
