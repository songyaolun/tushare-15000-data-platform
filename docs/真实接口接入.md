# 真实接口接入

接口能否调用以当前账户的真实请求为依据。官方文档用于说明权限、限制和数据含义，文档缺项不会阻止小范围只读验证，也不把独立权限类别等同于当前账户未授权。

## 2026-10-02 实测记录

## 扫描与保存样本

先导入目录，再显式扫描。凭据可以通过已有环境变量 `TUSHARE_TOKEN` 提供，也可以指定已有 dotenv 文件；命令不会复制该文件。

```bash
uv run tushare-hub --db data/live.duckdb catalog sync --fixture fixtures/catalog/official
uv run tushare-hub --db data/live.duckdb capability survey --live \
  --credential-file /path/to/existing.env --output data/live-survey
```

输出包括 `report.json`、各接口原始响应以及 `samples/<api_name>.json`。样本保存源字段、可生成的标准化记录和质量问题。只取政策中的样例范围；样本不推进历史水位，不计为全量采集或完成覆盖。返回的数据超过预期、主键缺失、来源字段变化等问题仍须在正式采集前处理。

默认扫描公共只读接口，包括原先按权限未知、独立权限或停更分类的接口。账户写操作 `p_save`、`p_delete` 永远不做探测；私有组合查询 `p_get`、`p_list` 仅在 `--apis` 明确选择时执行。期货 Tick 网盘交付不提供 API，报告将其列为排除项。

```bash
uv run tushare-hub --db data/live.duckdb capability survey --live \
  --apis trade_cal,namechange,fut_weekly_monthly --refresh \
  --parameters data/probe-parameters.json --output data/live-survey
```

`--parameters` 文件按接口名映射需要覆盖的请求参数，与政策样例参数合并，同名字段以文件为准。单接口 `capability probe` 的同名参数接收单个请求参数对象，合并规则相同。样例日期和代码不是全市场范围；当某类接口新增、停更或证券到期时，需要更新它的样例参数。

重跑默认复用同账户、同政策且原始文件仍存在的成功结果，也复用已确认的拒绝结果。`--refresh` 强制重新请求，开通权限或更换凭据后应执行刷新。修改政策后旧证据不再用于放行。原始数据和中断前结果保存在本地，可以继续扫描。每次报告只包含本次选择的接口；局部扫描应指定不同输出目录，避免覆盖完整报告。

## 如何理解结果

| 状态 | 含义 |
| --- | --- |
| available | 实际返回了非空、结构可解析的数据 |
| empty | 请求成功但该范围为空，不能据此声明已有数据覆盖 |
| unauthorized | 提供方拒绝权限或凭据；需要结合当前凭据和服务授权检查 |
| unsupported | 提供方明确表示接口不存在或不支持 |
| transient_failure | 网络、明确限流或临时服务错误 |
| contract_failure | 请求参数或响应结构异常，不自动归为缺权限 |
| excluded | 非 API 交付、写操作或未显式选择的私有组合查询 |

账户探测与目录证据分别存储。运行失败不把目录永久改为 blocked；成功也不伪造官方积分门槛、单次上限或更新时间。下一次文档同步不会抹掉探测记录。

## 正式采集

真实采集必须有同账户、同政策的成功请求证据；available 和 empty 均说明请求被接受。后者仍会在正式采集的空批次检查中失败。实测成功后，独立权限、未知权限、待复核和历史接口均可以进入相同的采集路径。

```bash
uv run tushare-hub --db data/live.duckdb ingest plan trade_cal 2026-09-28 2026-09-30 \
  --live --output data/trade-cal.plan.json
uv run tushare-hub --db data/live.duckdb ingest run data/trade-cal.plan.json --live \
  --credential-file /path/to/existing.env --references data/quality-references.json
uv run tushare-hub --db data/live.duckdb products build --source live \
  --as-of 2026-10-02 --output data/live-products
```

主键、必需字段、分页完整性、时间语义、交易日覆盖和参考数据检查继续执行。成功探测只解决调用能力；真实响应揭示的字段差异必须修正明确政策，不能用删除必需字段或清空主键让错误数据通过。

单个数据库只使用一个账户别名。其他账户应使用新的 `--db` 和 `--account`，不把一个账户的探测证据用于另一个账户。

## HTTP 与 SDK

普通 Pro SDK 方法把接口名和参数发送给 Pro 服务，然后将结果转换成 DataFrame。项目直接处理相同的 Pro JSON 协议，并使用 HTTPS、原始落盘和固定错误分类。

`pro_bar` 是组合方法。本项目已适配股票日周月、指数日周月，以及基金、期货和期权日线；支持区间内价格/成交量均线，股票日线换手率与量比，以及股票和基金固定锚点复权。底层响应先保存，派生响应记录来源哈希。

复权必须显式提供 `anchor_factor`，不会沿用随最新数据变化的隐式锚点。均线窗口不足时返回空值，不假装已经取得区间外预热数据。当前不声称完全兼容 SDK 所有资产、分钟频率或历史参数。组合行情保留源单位，跨资产比较需使用对应底层接口单位。

本次核对的官方源码来自 `https://github.com/waditu/tushare/blob/master/tushare/pro/client.py` 与同目录 `data_pro.py`。该源码中的普通客户端默认使用 HTTP，本项目未启用该默认路径。
