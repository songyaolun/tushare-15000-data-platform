# 主题预期与基金研究

本文说明 P02、P05、P08 的业务加工口径。指标来自已适配的有限输入，包含来源字段证据和缺口原因；接口登记、程序执行成功或合成测试通过，都不代表正式数据已经达到 `observed`。

当前有两项必须提前说明的限制：官方契约没有 `profit_scope` 和 `return_basis`，新输入投影也不会保留这两个额外字段。因此，正式链路不能自动认证预告与快报的利润归属口径，也不能自动认证基金与基准的收益口径。对应的兑现差和基准跟踪差保持 `unknown`，不会为了得到数值而补造字段。

## 产品入口与证据约定

| 产品 | 结果标识 | Python 入口 | 主归属接口数 |
| --- | --- | --- | ---: |
| P02 主题机会 | `theme_opportunities/v1` | `build_theme_opportunities(inputs)` | 22 |
| P05 预期修正 | `expectation_revision/v1` | `build_expectation_revision(inputs)` | 7 |
| P08 ETF 暴露 | `etf_exposure/v1` | `build_etf_exposure(inputs)` | 18 |

三个入口均接收 `ResearchInputs`，返回 `tuple[ResearchResult, ...]`。输入中的原始数值不会直接进入算术：程序只使用 `ResearchRow.numeric` 中已认证的事实。单位不符、币种不符、隔离质量或数值缺失都会使相关指标保持未知。金额和价格事实还受共用模型的 CNY 币种检查约束，不能把外币数值混进人民币指标。

当前目录身份、来源内身份和部分消费字段缺失属于观察注记，已有且已适配的字段仍可参与观察，相关原因继续保留。容量超限、未来可见性和隔离质量等拒绝条件不会因此放宽。

同源已排除行的 `rows_excluded_by_adapter`、`row_unavailable`、`future_business_date`、`quarantined_or_unknown_quality` 只保留为审计注记，不连带清空健康保留行。每条保留行仍检查自身可见性与质量，容量超限和实体歧义仍会拒绝相应范围。

指标的 `evidence_refs` 指向实际存在的来源字段，保留接口、来源记录、业务组、契约及观察／公开时间。`details.sources` 提供完整行数、逐字段非空计数和确定性来源摘要。来源摘要的字段引用按每字段最多 8 条抽样，指标另外保留参与公式的直接引用；展示标签最多抽样 32 项。业务计数和分母仍使用完整的已保留输入。这里的“完整”指适配层未因容量拒绝的研究输入，不表示全市场覆盖。

所有结果均为观察研究，不生成自动交易动作。运行与存储说明见 [全产品离线研究.md](全产品离线研究.md)。

## P02 按来源观察主题状态

主题名称相同不能作为连接依据。只有显式实体绑定或有证据的目录别名，才允许相关来源进入同一实体结果。没有目录证据时，来源内序列身份只支持该来源内部研究。

| 来源 | 业务作用 |
| --- | --- |
| `dc_index`、`tdx_index`、`ths_index`、`index_classify` | 目录、类型、层级及供应商范围；同序目录冲突使目录一致性未知 |
| `dc_member`、`tdx_member`、`ths_member`、`kpl_concept_cons` | 成员快照、权重或题材解释；分别保留来源口径 |
| `ci_index_member`、`index_member_all` | 行业层级及成员区间线索；保留一级至三级代码 |
| `dc_daily`、`tdx_daily`、`ths_daily`、`ci_daily`、`sw_daily` | 最新可见收益、量额、估值或涨跌分布 |
| `dc_hot`、`ths_hot` | 来源内排名与关注度；可形成证券关注旁证，不能按题材文本自动归属主题 |
| `limit_cpt_list`、`kpl_list` | 涨停广度、供应商题材标签及异动理由；后者不升级为公告事实 |
| `moneyflow_cnt_ths`、`moneyflow_ind_dc`、`moneyflow_ind_ths` | 来源内资金方向、公司分母及资金口径 |

### 主要指标如何计算

下表中的成员指标以东方财富来源为例；其他成员接口使用各自 API 名称作为前缀。

| 指标名 | 计算口径与必要证据 |
| --- | --- |
| `dc_member_observed_members` | 有业务日时取最新业务日的去重成员数；全部缺业务日时，只统计最新来源观察时刻的成员记录组。缺业务键或同键同序冲突时未知 |
| `dc_member_effective_members` | 全部成员区间均有认证后，统计研究时点仍有效的成员；原始日期文本不自动成为有效期认证 |
| `dc_member_member_price_coverage` | 有明确关系且同日价格可用的成员数 ÷ 贡献成员数；成员业务日期未知时，覆盖率也保持未知 |
| `dc_member_member_up_fraction` | 全部贡献成员价格齐备后，上涨成员数 ÷ 贡献成员数 |
| `dc_member_equal_weight_return` | 全部贡献成员同日 `daily.pct_chg` 的等权平均，不代表可交易组合收益 |
| `ths_member_observed_weight_sum` | 完整成员快照中认证为比例的权重之和；不猜原始百分数单位 |
| `tdx_daily_directional_breadth` | `up_num / (up_num + down_num)`；分母仅含上涨与下跌样本，平盘数量未知 |
| `limit_cpt_list_limit_up_breadth` | `up_nums / cons_nums`；要求正分母且上涨数不超过成分数 |
| `ths_daily_pct_change` | 最新来源收益比例，接受已完整认证、量纲为 `ratio` 的 `ratio`／`fraction` 存储单位，统一以有符号 `ratio` 输出；不声称已计算长窗口动量 |
| `dc_hot_inverse_rank_0` | 来源内首个排名分组的 `1 / rank`；分组后缀见 `details.sources.dc_hot.rank_groups` |
| `moneyflow_ind_ths_per_company_flow` | 认证净额 ÷ 正的认证公司数，单位为元／公司 |
| `price_flow_confirmation` | 同一显式主题实体的最新行情日，至少有一条价格和一条资金观察，所用同日数值均可用且全部为正时为 1；数值齐备但不共同为正时为 0，否则未知 |

成员贡献接受两类证据链：已确认且有效的 `theme_member` 关系；或者成员接口明确的股票代码，加上 `tushare_stock` 时点别名，再定位到同生命周期的 `daily` 行。仅有相同代码字符串不够。代码对应多个实体、股票别名缺失、价格错日或任一成员缺价格时，整体广度与等权收益都保持未知。

成员区间全部认证后，贡献集合使用当前有效成员；否则只保留观察快照口径。CI、申万或同花顺成员可能只有关系字段与纳入／退出日期，没有成员业务日。这类输入可报告最新来源观察组中的记录数和去重成员数，不能解释为某个历史交易日的完整成分。

这类结果将 `snapshot_date` 保持为空，把真实来源观察时刻单独写入 `snapshot_observed_at`，并标记 `snapshot_scope=latest_observed_at_records`。`observed_snapshot_record_count` 是该观察组的全部记录数，`observed_member_key_coverage` 是成员代码非空的记录数占比；后者不表示全市场覆盖或关系已无冲突。有真实有效期认证时仍可统计当前有效成员，但成员价格覆盖、上涨广度与同日贡献在缺业务日期时均保持未知。当前目录别名和观察时间都不能反向证明历史成员关系。

不同资金来源不相加，不同供应商的主题价格序列不拼接。排名只说明来源内部关注程度，不能直接解释为统一拥挤分数。

## P05 保留公告顺序和机构口径

`forecast` 与 `forecast_vip` 用于预告区间核对，`express` 与 `express_vip` 用于快报核对。程序按报告期、公告日、事件类型及显式口径分组。相同事件的普通版与 VIP 版认证值一致时，只保留一个经济事件；取 VIP 作为稳定证据来源不会增加事件分母。认证值或审计状态冲突时，该事件不进入数值计算，并记录 `disclosure_version_conflict`。

报告期来自明确的 `end_date`，事件先后来自公开可用时间。缺少公开时间时，不会使用报告期或采集时间替代公告顺序。同一报告期最新公开时点仍有多个事件时，不任意选择其中一个。

### 预告、快报和机构预测指标

| 指标名 | 公式或加工口径 |
| --- | --- |
| `forecast_profit_midpoint` | `(net_profit_min + net_profit_max) / 2`；要求上下限均已认证为元，且下限不大于上限 |
| `forecast_profit_range` | `net_profit_max - net_profit_min` |
| `forecast_midpoint_revision` | 同报告期、同显式口径的最新预告中点减去先前预告中点 |
| `forecast_economic_events` | 通过公开时间、期间及版本核对的预告事件数 |
| `express_economic_events` | 通过相同核对的快报事件数 |
| `express_net_income`、`express_revenue` | 最新目标报告期快报的认证净利润及收入；审计标签另保留在 `details.realization.audit_status` |
| `realization_midpoint_gap` | 后续同期间快报净利润减去快报前最后一次可见预告中点；须明确认证利润归属口径一致 |
| `realization_outside_range_gap` | 快报净利润落在预告区间内时为 0，低于下限时为负差，高于上限时为正差；前提与中点差相同 |
| `institution_forecast_cohort_count` | 按机构、预测期间及显式口径划分的研报群组数 |
| `broker_recommend_observed_coverage` | 按月份、机构及证券代码去重后的观察推荐数 |
| `stk_surv_observed_coverage` | 按证券、调研日、接待机构及接待方式去重后的观察事件数 |

`report_rc` 不同机构的预测不会平均成一个预测值，也不会互相计算修正。每组保留以下指标，`<key>` 为分组的确定性标识，可在 `details.institution_revisions.cohort_samples[].metric_key` 查到：

- `institution_<key>_np_estimate`、`institution_<key>_eps_estimate`：该组最新可见的净利润和每股收益预测。
- `institution_<key>_np_revision`、`institution_<key>_eps_revision`：同组最近两次唯一公开版本的预测差。

单位、量纲或币种不一致时，修正未知。同机构同公开时点存在多作者／多记录冲突时，该时点也保持未知。预测期间 `quarter` 保留来源文本，不擅自转换成财务报表截止日。

所有群组均参与完整计数与确定性摘要；结果只展示前 32 组的具体指标和样本，避免结果体积随机构数膨胀。推荐和调研只表示观察到的关注活动，不推导机构仓位、买入行为或资金流向。

## P08 在没有用户组合时保留 ETF 本体

ETF 到基准的连接必须来自 `etf_basic.index_code`，再精确定位指数资料、权重及可用的基准行情。基金名称或 `fund_basic.benchmark` 文本不作为指数映射依据。基准成分表示观察到的基准结构，不等于基金实际持仓。

| 来源 | 业务作用 |
| --- | --- |
| `etf_basic`、`fund_basic`、`fund_company` | ETF 类型、基金市场、费用及管理人主体；管理人按完整名称匹配，并核对主体代码 |
| `etf_index`、`mkt_idx_bmk`、`index_weight` | 基准发布方、调整周期、分类及成分权重 |
| `etf_sh_cons`、`etf_sz_cons` | 分交易所保留申赎篮子、股数及现金替代约束 |
| `fund_daily`、`etf_limit`、`fund_factor_pro` | 成交活跃度、价格边界及供应商量价核对 |
| `etf_share_size`、`fund_share`、`fund_nav` | 规模、份额及公告后净值核对 |
| `fund_adj`、`fund_div`、`fund_manager` | 固定锚点复权、分红阶段与经理任职变动 |
| `slb_len_mm` | 做市借券供给与库存变化，不解释为投资者做空 |

只有场外 `fund_basic.market='O'` 且没有明确 ETF 档案时，不生成 ETF 候选。缺少用户组合时，仍可输出基金本体观察，`portfolio_overlap` 保持未知。

### 暴露、流动性和份额变化公式

| 指标名 | 公式或加工口径 |
| --- | --- |
| `benchmark_observed_weight` | 最新指数快照中认证成分权重之和；缺值、负数、冲突或明显超过 1 时未知 |
| `benchmark_observed_hhi` | `Σ(weight / 观察权重总和)²`，衡量观察部分的集中度，不声称全基金集中度 |
| `etf_sh_cons_benchmark_observed_overlap`、`etf_sz_cons_benchmark_observed_overlap` | 同日篮子与基准成分的交集数量 ÷ 并集数量，属于观察集合的重合度 |
| `etf_sh_cons_positive_quantity_fraction`、`etf_sz_cons_positive_quantity_fraction` | 正股数成分数 ÷ 完整篮子成分数；不同证券的股数不相加当成经济权重 |
| `etf_sh_cons_mean_cpr`、`etf_sh_cons_mean_rdr` | 沪市完整篮子中认证现金替代率的等权均值；深市使用 `etf_sz_cons` 前缀 |
| `etf_sh_cons_sca`、`etf_sz_cons_sub_cc`、`etf_sz_cons_red_cc` | 各来源现金替代金额字段的认证合计；不跨交易所混算 |
| `fund_turnover_amount`、`fund_volume_lots` | 认证的基金成交额与手数 |
| `turnover_to_assets` | 同日 `fund_daily.amount / etf_share_size.total_size` |
| `price_nav_premium` | 同条 `etf_share_size` 的 `close / nav - 1`，用于规模表内估值核对；交易可行性另作检查 |
| `size_nav_identity_gap` | `total_share × nav / total_size - 1`；要求份额为份、净值与规模分别使用认证元口径 |
| `published_nav_difference` | 同净值日 `fund_nav.unit_nav / etf_share_size.nav - 1`；净值还必须有公开时间 |
| `adjusted_nav_uplift` | 同条已公开净值的 `adj_nav / unit_nav - 1` |
| `published_share_difference` | 同日 `fund_share.fd_share / etf_share_size.total_share - 1` |
| `provider_price_difference`、`provider_amount_difference`、`provider_volume_difference` | 同日 `fund_factor_pro` 对 `fund_daily` 的相对差；分别核对价格、成交额和手数 |
| `price_limit_distance` | `min(close - down_limit, up_limit - close) / close`；要求同日、正量额、有效成交价且价格在边界内 |
| `share_change`、`share_change_ratio` | 最近两个唯一份额快照的差值及相对变化，起始份额必须为正 |
| `share_change_nav_proxy` | `份额变化 × 新快照净值`；只作申赎估值代理，未认证拆并份等公司行动，不能当实际现金净流入 |
| `adjusted_price_return` | 固定首尾锚点的 `(close₁ × adj_factor₁) / (close₀ × adj_factor₀) - 1` |
| `benchmark_tracking_difference` | 基金复权端点收益减去同端点基准收益；基金与基准必须有一致的显式 `return_basis` |
| `lending_inventory_change` | 同条做市借券记录的 `cls_inv - ope_inv`，单位为股 |

复权收益要求保留行情的每个点都有因子，不能跳过失败端点来拼出收益。参考价、无成交状态、非正量额和缺价格都不能参与交易距离或复权价格收益。端点收益差不等于年化跟踪误差，也不能据此推断长期表现。

`implemented_dividend_events` 按已实施标签及已到除息日统计事件，预案和未来除息不计成已实施现金事件。`latest_dividend_cash` 保留最新可用分红值。`active_fund_managers` 依据可解释的任职起止日计数，任职变动不升级为个人业绩归因。`same_manager_observed_etfs` 只统计明确管理人主体下观察到的 ETF 数量，不代表资产加权的集中暴露。

## 常见未知原因如何解释

| 原因码 | 含义 |
| --- | --- |
| `unit_or_value_unverified` | 字段没有可用的数值、单位或币种认证 |
| `membership_snapshot_ambiguous` | 成员数据日、业务键或同序版本不能唯一解释 |
| `membership_effective_interval_unverified` | 成员有效期未完整认证，只能保留观察快照 |
| `membership_business_date_unknown` | 可统计当前来源观察记录，但缺少成员业务日，不能认证同日价格覆盖、广度或贡献 |
| `member_relation_or_aligned_prices_missing` | 成员关系、生命周期别名或完整同日价格缺失 |
| `aligned_theme_price_flow_unavailable` | 主题价格与资金不在同一可用日期，或相关数值未知 |
| `forecast_interval_unverified` | 预告上下限缺失、单位不明或范围倒置 |
| `comparable_prior_forecast_unavailable` | 没有同报告期、同口径的唯一先前预告 |
| `disclosure_version_conflict` | 普通版与 VIP 版同经济事件存在冲突，相关事件不参与计算 |
| `institution_latest_estimate_unverified` | 机构最新预测缺数值认证，或最新公开版本不唯一 |
| `comparable_institution_prior_unavailable` | 同机构同期间没有可比的唯一先前预测 |
| `profit_scope_unverified` | 不能证明预告与快报具有相同利润归属口径 |
| `realization_period_mismatch` | 比较双方报告期不同 |
| `aligned_comparable_values_unavailable` | 核对字段错日、量纲／币种不同或分母不为正 |
| `benchmark_weights_unverified` | 权重缺失、单位未认证、成分冲突或总量异常 |
| `aligned_basket_benchmark_unavailable` | 篮子与基准成分缺失或快照日期不一致 |
| `manager_legal_identity_unverified` | 管理人主体代码缺失或同名对应多个主体 |
| `fixed_anchor_adjustment_unavailable` | 复权因子、端点或有效成交价格不齐备 |
| `aligned_benchmark_return_basis_unverified` | 基准端点、数值可比性或收益口径无法认证 |
| `user_portfolio_not_provided` | 未提供用户组合，ETF 本体结果仍可保留 |
| `historical_pit_uncertified` | 当前观察不能宣称具有历史时点认证 |

`unknown` 不是数值 0，也不是“没有风险”。应同时读取指标状态、原因码、来源日期和证据引用，不能只读取数值列。

| 额外语义字段 | 契约与投影结果 | 当前影响 |
| --- | --- | --- |
| `profit_scope` | `forecast`、`forecast_vip`、`express`、`express_vip`、`report_rc` 的官方字段中均无此字段；不在对应 `API_FIELDS`，新投影也不保留人为额外加入的同名列 | 不能自动认证跨预告／快报利润归属；`realization_midpoint_gap`、`realization_outside_range_gap` 保持未知 |
| `return_basis` | `fund_daily` 与 `index_daily` 的官方字段均无此字段；`fund_daily` 的新投影不保留人为额外加入的同名列；`index_daily` 虽走旧来源读取，也没有官方口径证明 | `benchmark_tracking_difference` 不能自动成为可用指标 |

单测会显式构造这些语义值，用于验证“证据齐备后公式是否正确”以及“证据不足时是否关闭”。这类合成输入不代表官方契约已经提供该字段，也不能证明正式链路可计算相同结果。不能仅因双方字段都写着“净利润”就认定利润归属相同，也不能因基金已有复权因子就认定基准包含相同的分红处理。

若后续需要开放这几个指标，应先建立可回查、版本化的语义认证与投影契约。当前版本未提供这种自动认证路径，保留未知是预期行为。

## 时点与验收边界

观察时间、公开时间、数据日、报告期和生效区间分别保存。只能在截止前可见的证据上计算；回填记录或当前目录不能补成历史上已经可见的事实。有效期未认证时也不能声称完成历史成分回测。

同输入的计数、摘要、抽样和指标命名保持确定性。共享基准的权重、行情索引和来源摘要会复用，避免每只 ETF 重扫同一组基准资料。单结果仍受全产品流程的 8MiB 上限约束，不能通过增大结果上限或截断业务分母掩盖缺口。

正式数据是否满足 `observed`，须由实际运行后的逐接口审计确认。某接口已有可用证据，也不代表全部字段、全部实体或历史 PIT 均合格。
