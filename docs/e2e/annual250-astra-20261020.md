目标是百万元原筛选范围账户在 2021-10-18 至 2026-10-16 共 1212 个
交易日的 CAGR 超过 250%，按 `(期末净值/本金)^(250/1212)-1` 计算。
另报完整逐年收益、2022—2025 完整自然年的算术平均，以及含首尾部分年度的
六段算术平均；不得用这些平均数替换 CAGR。全五年拟合与选择，无金融 holdout，
但数据时间可见性和软件测试仍必须通过。

不能把差异全部解释成容量影响。旧的退出搜索在其他评分下已做过，本轮是新47列
评分下的执行敏感性实验，不声称首次发现这些参数。

停牌涨跌停及分红，均沿用。正常单边滑点5bp，双成本同时放大手续费和滑点。

容量验收另列：现有日线回放没有逐笔市场参与率上限，前日成交额准入不能替代
容量证明。首轮只保留原成交代理作为探索；后续逐笔核验实际执行日、股数、价格、
金额单位和成交额占比，列出异常而非只报均值。即使名义 CAGR 达到250%，没有

## 成交证据增补阶段

适用 revision：本分支增加 `--capture-execution-evidence` 的提交，精确 SHA 写入运行
清单。依赖仍使用本计划原冻结面板、47 列评分和同一独立 Python 3.11 环境；无跨仓
依赖更新，不使用凭据或联网数据。

离线必跑：运行 `tests/test_execution_evidence.py` 以及资金、候选分配和分红相关回归。
覆盖空账户、正常成交、未知成交额、同日分红支付、卖出后支付、送股解锁与样本末
尚未支付/上市的权益。开启证据前后原结果必须完全相同，新模块目标覆盖率100%。

真实缓存验收：原筛选范围100万元和主板12万元，各重跑baseline47与holding15的
正常/双成本，共八账户；原daily/trades/entries必须精确复现。新增fills.csv记录
实际执行日、股数、原始价格、费用、成交后现金和当日行情；distributions.csv记录
登记/权益确认/支付/送股解锁；positions.csv保留每日原始持仓批次和估值。
独立脚本不得调用模拟器费用或资金函数，必须复算费用、现金、股数、分红应收和净值。

容量检查按每笔成交与同证券同日合计分别报告，Tushare日线amount单位为千元。
缺失、非正、非有限金额及价格异常全部保留，不能删分母。完整日成交额只用于
事后审计，不能用于当天开盘决策，也不能据此证明开盘分钟容量。当前没有参与率
硬上限，必须明确报告；没有分钟证据时不能声称容量通过。

桌面/390x844浏览器与跨端UI一致性：not applicable，本阶段不改前端或发布产物。
失败关闭：CSV差异、独立核算失败、金额单位无依据或异常未解释时停止收益有效性
结论，保存完整异常。飞书、部署、交易和调度均不执行；任何后继真实写操作另需
显式授权。证据保存到私有实验缓存，提交中只记录可公开的汇总与SHA。

实际结果：八账户旧CSV全部逐字节一致，独立核账通过；33885笔成交全部匹配源
