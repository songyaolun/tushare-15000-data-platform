目标是百万元原筛选范围账户在 2021-10-18 至 2026-10-16 共 1212 个
交易日的 CAGR 超过 250%，按 `(期末净值/本金)^(250/1212)-1` 计算。
另报完整逐年收益、2022—2025 完整自然年的算术平均，以及含首尾部分年度的
六段算术平均；不得用这些平均数替换 CAGR。全五年拟合与选择，无金融 holdout，
但数据时间可见性和软件测试仍必须通过。

第一轮冻结 without_cash47：模型 SHA256
`dd32f7473a714d54f61ab3af7d11b55472aff2d1609a14531e438ea53a8f7897`，
评分 SHA256 `3aebe8d5f9eed4e9ffbbe54de490fb813094a716ce14c14dfec15182a2768480`。

数据轴与训练矩阵继续复用已冻结材料，不重新采集现金源、不改其修复分支。

不追加交叉组合。按照正常 CAGR 和双成本 CAGR 分别报告最高者，不设回撤硬门槛。
必须公开全部失败、回撤、费用、交易数和持有时间。两个本金账户还存在范围差异，
不能把差异全部解释成容量影响。旧的退出搜索在其他评分下已做过，本轮是新47列
评分下的执行敏感性实验，不声称首次发现这些参数。

共同约束：Top10、信号日一级行业名额1、单股5%、行业持仓40%、广度40%
对应15%/100%新买入上限、5%追价、下一开盘、单日买单、现金、整手、T+1、
停牌涨跌停及分红，均沿用。正常单边滑点5bp，双成本同时放大手续费和滑点。

离线前置条件：Linux Python3.11.2、冻结 uv.lock、原始面板及模型缓存；所有
Python 命令使用 `uv run --frozen --python 3.11`，不使用 PYTHONPATH。
软件测试无需 Token 或网络。真实数据补缺不是本轮必跑链路，不调用外部 sink。

必跑：参数非法值单元测试和100%分支覆盖、Ruff、默认四账户逐日逐笔基准复现、
28账户完整CSV独立计算 CAGR/回撤/年度/净收益/现金。每个输出须有输入与脚本SHA、
协议、metrics、daily/trades/entries/selections和审计回执。输出目录必须全新；
错SHA、错轴、合格候选缺评分、参数非有限或越界均失败关闭。

容量验收另列：现有日线回放没有逐笔市场参与率上限，前日成交额准入不能替代
容量证明。首轮只保留原成交代理作为探索；后续逐笔核验实际执行日、股数、价格、
金额单位和成交额占比，列出异常而非只报均值。即使名义 CAGR 达到250%，没有
完整独立账本证据与成交容量核验也不得标记目标达成。缺少分钟级证据时，
先卖后买使用同日开盘价仍是明确限制，不伪造分钟成交。

外部副作用边界：允许当前研究分支commit/push/MR；不合并、不部署、不发飞书、
