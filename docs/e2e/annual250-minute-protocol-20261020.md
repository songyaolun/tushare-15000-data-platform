# Top15执行证据验收计划

适用revision为`5bfb8e28a70a5dea65c3c54a9f950a560acc52c4`，无依赖仓变化。
沿用51200轮评分、Top15、2%预算、开盘现金约束，固定两档历史限额、两范围及双成本八账户。
本阶段只整理已揭示结果的证据需求，不训练、不重放、不修改原账本，也不申请新权限或在线取数。
Python3.11通过`uv run --frozen`运行，清除PYTHONPATH；离线链路无需凭据。

## 全量需求核验

先冻结八账户全部文件、源码、上下文和上一阶段证据清单。逐笔保留买卖成交，按前一交易日
收盘持仓重建全部待卖队列，覆盖正常触发、替换触发、部分卖出、零成交和不能下单的等待。
当天股数从成交及收盘持仓反推，核对能下单记录的原始请求股数；现金分红和送股不通过
直接沿用昨日股数来猜测。末端待卖单单列，不伪造样本外日期。

以证券日去重请求；账户、成交、队列观察和唯一证券日分母分别报告。同一证券日跨账户
共享市场数据，但账户之间不合并资金或订单。逐笔金额、股数及异常标签用原CSV的独立SQL
复算，两个方向均做集合差集。优先级只决定取数顺序，不得删掉普通成交或等待记录。

现有分钟数据从冻结的原始响应重建，按证券与时间去重，再与需求全集核对。只读官方文档
及已有接口合同，分开记录文档能力、历史探测和当前权限。缺单位、时区、区间语义、历史
覆盖或当前授权时保留未知，不能凭旧成功响应宣称可取完整五年。

## 失败关闭与交付

输入哈希变化、漏账户、记录差集非空、金额或股数不一致均停止交付并保留失败证据。
取数协议必须明确分页截断、缺行、重复冲突、停牌和时间窗口的判据，保存未覆盖代码及日期。
分钟OHLC或竞价汇总只能检验价格和市场成交量，缺少订单及排队证据时不能认证实际成交。
日历CAGR以2021-10-18至2026-10-16的1824天、365.25天年基准计算，沿用已核验结果。

文档和私有诊断不改变前端，桌面及390x844浏览器验收not applicable；跨端一致性由冻结
SHA256核验，不宣称Mac实测。真实行情下载、部署、飞书、交易、调度和MR合并均不执行。
本轮可读取公开官方说明；后续在线探测与下载需另行准入，不能将本计划视为取数执行记录。

通过标准是完整需求明细、独立SQL核验、源文件哈希和接口证据协议均可核验。证据留私有缓存，
仓库提交本计划与结果报告。阶段通过不代表收益可以兑现，总目标继续保留执行容量缺口。
