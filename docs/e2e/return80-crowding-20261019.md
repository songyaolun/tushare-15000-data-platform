## 离线必跑链路

1. 软件门禁：`uv run --frozen pytest tests/test_discovery_industry_crowding.py -q`。
   Ruff检查新增模块与测试；Mypy检查新增模块；`git diff --check`。
   覆盖率用独立 coverage 配置的 `include=*/strategy_discovery/industry_crowding.py`
   运行并要求100%。不要把具体模块名作为 pytest-cov 的 source：本机该路径会在
   pytest收集前重复探测导入NumPy/DuckDB，导致扩展模块初始化失败；直接pytest通过。
2. 数据审计：逐文件记录SHA256，验证日期不重复、31/31同级公开行业齐全、金额
   有限且非负。任一行业缺失使同日全部占比未知，不缩小分母、不补零。
3. 历史限制：2021版指数正式推出日为2021-12-13，之前的回溯序列全部弃用。
   为保证365自然日窗口充分预热，拥挤度最早2022-12-13可用。使用现有domain
   `calculate_historical_percentiles`，平均并列秩除以样本数，含当日；要求窗口
   所有预期交易日都有样本。目录为供应商当前SW2021版本，不能声称当日归档PIT。
4. 特征前缀验证：31行业截断到第1000日的百分位必须与完整计算前缀逐值相同。
   候选映射使用原始按生效/退出日生成的行业矩阵；5日变化要求六日行业不变且
   百分位都存在。改变未来成员或未来数值不能改变过去特征。
5. 固定490655条成熟训练行，按交易日等权，不留金融验证集/测试集。
   仅训练原36列+拥挤度、原36列+拥挤度及5日变化两个模型；1600轮等参数全固定。
   末31个信号交易日只排除训练，回放保留完整区间。缺失保留NaN。
6. 将每个新模型导出为便携JSON，对全部520690条候选比较NumPy推理与训练库，
   最大差异须为0。验证冻结原模型SHA。
7. 三模型分别运行正常/双倍成本，保持原轮换、Top10、行业一只、5%单股、40%行业、
   广度仓位、4.5/8/30退出参数。先完整五年，再从2022-12-13空仓启动，并对三组
   使用完全相同的拥挤度及变化可用候选掩码。总计12个账户，不进行规则搜索。
8. 完整五年原模型两成本的逐笔成交、入场日和日净值必须重现旧轮换账本，日净值
   只允许1e-7元舍入差。每账户运行已有CSV核账，保存审计结果。
9. 报告总收益、年化、回撤、胜率、交易次数、换手、费用、逐年表现及错过行情。
   错过行情用基准独有/新增独有候选中的正收益独立交易标签计数，不能把独立标签
   收益求和当成账户机会损益。全样本结果不作样本外解释。

## 失败关闭与副作用

缺目录、缺分母、成员冲突、未知行业、预热不足均保留unknown。
不能用今天成员回填历史，不能为凑五年覆盖伪造SW2014目录。
原始数据缺失、模型SHA不符、基准不一致、便携预测不一致或核账失败均停止对应阶段。
真实数据只读补采须另列来源、权限、调用规模和私有缓存路径；本次已有原始数据足够，
没有调用真实API。禁止飞书、Cloudflare、券商、调度注册、合并和生产模型切换。
