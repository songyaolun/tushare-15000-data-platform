# 历史流动性候选筛选验收

适用revision：从 `3819c93294d8966d90dfe20df1fd5ddd23e7e454` 起的本分支候选
筛选提交，精确执行SHA写入实验清单。不更新依赖仓。使用独立Python 3.11环境，
通过 `uv run --frozen` 执行；只读冻结面板、47列评分与分红缓存，无需凭据。

## 收益运行前冻结

原候选历史可成交金额四分位约55万、101万、217万元，据此预登记50万、100万、
200万元三个固定门槛。另跑受约束baseline47，共四方案，每方案含100万元原范围、
12万元主板，各正常与双成本，共16账户。所有结果均报告，失败不删。

在信号日收盘，计算包含当日及之前19交易日的成交额中位数，与信号日成交额取
较小值，再乘1%。只使用已结束的交易日，不读取执行日最终成交额或未来NAV。
门槛固定，不随未来资产变化。全五年分布用于预登记，仍属样本内研究。

筛选发生在每行业1只的Top10之前。47评分排序、Top10总数和行业名额保留，允许
原候选池内榜外证券补位。共同资格仍在Top10之后检查，不因资格失败再次补位。
原发布／技术资格不变，本实验为独立研究策略，不能当作生产规则已更新。

执行继续保留1%历史限额、部分退出、费用、现金、T+1、停牌限价、送股锁定、
单股5%及行业40%限制。使用holding30基准，不能拿旧无约束151%至155%作直接对照。

## 离线门禁和通过标准

- 单元测试覆盖输入校验、全部排除原因、窗口边界、改变未来数据不影响信号选择、
  空候选以及观察器不改变原交易结果。新增筛选模块目标分支覆盖率100%。
- 每条原候选保留信号日期、代码、评分、行业、历史窗口、缺失／负值数量、参考
  金额、门槛、排除原因、原Top10与新Top10身份。不能只保存筛选后名单。
- 独立重新计算全部原候选的历史参考与选择顺序，核对各原因数量、Top10行业
  名额、榜外补位和后置共同资格拒绝。执行限额逐单、证券日买卖累计额均复算。
- 16账户独立CSV账本核对费用、股数、分红、现金和日净值，独立计算250日CAGR、
  回撤与各年实际收益。基准六类CSV与上一阶段精确对照。
- 记录开盘订单的信号预算、当时单股上限、现金、目标敞口、行业余量和流动性
  余量，同时记录配对／预备卖单阻塞、价格资格失败及零股订单。
- 每日记录目标与实际敞口、持仓和待卖数、候选数、新候选数、常规名额、排单数
  与未用名额。低敞口原因以这些观察分解，竞争限制可能同时出现，不把计数强行
  加总成互斥的收益归因。流动性缩量金额仅表示当时未成交需求，不是反事实收益。
- 按年份报告复投后订单预算与历史容量比、买入缩量、末端余仓和事后日参与率。
  成交价、限价、日金额及窗口成交额与只读源库复核；未知量保留分母。

真实新数据查询为可选阶段，本轮不采集；数据缺失或账本错配时失败关闭。
