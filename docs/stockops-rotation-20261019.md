# 满仓替换回测与产品规则

样本为2021-10-18至2026-10-16，共1212个交易日；行情预热自2020年开始。
使用全部五年进行模型拟合和规则选择，没有金融验证集或测试集。结果是样本内描述，
不证明未来收益或样本外alpha。软件测试单独执行。

原Top10每行业一只、固定模型、止盈4.5%、止损8%、最长30日、单股5%、行业40%、
广度40%对应15%/100%新买总仓上限保持不变。新增规则仅在持仓名额刚好满额且没有
正常卖单时触发：持有至少10日、复权价格收益≤1%、五日收益≤0，优先替换最久持有者。
新股必须在当日Top10内、未持有、资格通过、模型分≥0。每天最多一对，配对卖出实际
成交才允许买入。弱市超额持仓不替换，也不强平。

## 同口径结果

| 方案 | 年化收益 | 最大回撤 | 胜率 |
| --- | ---: | ---: | ---: |
| 原方案 | 93.91% | 7.84% | 74.34% |
| 替换方案 | 98.44% | 7.54% | 72.60% |
| 原方案双成本 | 83.80% | 7.79% | 73.66% |
| 替换方案双成本 | 87.48% | 7.99% | 71.72% |

双成本指把模拟费用和滑点都加倍，并重新回放整手、现金与仓位约束，不是把收益简单打折。
正常成本原方案1843笔平仓，替换方案1934笔，118次替换退出。每单平均净收益
3.69%→3.64%，平均持有11.02→10.58日，平均仓位73.91%→74.16%。收益改善主要
来自更快释放低效持仓，胜率略降。

## 探索和执行审计

首轮24组提前退出/配对替换，加基线和7组双成本共32组；第二轮20组邻近参数检验，
包括8/10/12日、收益0/1/2%、候选分门槛、趋势/行业确认和每日两只。10日/收益≤2%
正常成本年化99.51%，但双成本87.40%且回撤较差，因此采用≤1%。每日两只双成本
年化86.48%、回撤8.85%，不采用。持仓日评分覆盖仅30.54%，不把旧入场分当作剩余收益。

真实现金账本包含整手、T+1、次日开盘、涨跌停、滑点费用、分红和送股锁定。
止盈止损是收盘触发、下一可成交开盘执行，不保证盘中点位成交；不能把8%当最大损失。
