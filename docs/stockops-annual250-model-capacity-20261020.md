# 模型容量实验结果

本轮100万元原范围正常成本最高CAGR为147.67%，对应31叶3200轮。
两组新模型只增加拟合容量，全部12账户保留原1%历史成交限额、部分退出、现金和费用规则。
仍未达到250%数值目标；本轮仍为全五年样本内拟合，日线执行约束未构成开盘分钟容量认证。

31叶3200轮主账户正常与双成本分别比直接基准提高29.20和31.01个百分点，
63叶1600轮分别提高19.41和19.60个百分点。两种扩容都有改善，增加轮数在四个账户中均更高。
改善并非逐年一致：31叶3200轮主账户2024年正常成本收益90.89%，低于基准102.78%。
训练误差和账户收益一起改善，只支持继续检验这条样本内研究路线，不能据此判断泛化能力。
