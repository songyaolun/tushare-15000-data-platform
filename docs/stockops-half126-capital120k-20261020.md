# half126：12万元主板账户的2%、5%、10%仓位对比

实测支持降低2%方案的过度分散程度，但5%与10%各有取舍。固定原交易规则时，5%的五年年化更高、最大回撤更低；2026年初空仓启动时，10%的收益更高，持仓也更少。不能把尚未验证的10%建议描述成全面优于5%。本次没有修改生产仓位配置。

这些收益来自同一个全样本拟合及选参模型的历史重放，不是样本外验证，也不是未来收益预期。年度收益特别高，包含训练和选参覆盖时期；核账通过证明交易与算术口径一致，不能证明策略可在未来复现。没有为了比较三个仓位重新训练或重新运行预测。

## 固定条件与范围

- 本金120000元，起始0持仓；范围仅沪深主板，排除创业板、科创板、北交所和B股。市场广度和模型特征仍保留原全市场口径。
- half126冻结预测、每日Top15、每行业每天至多一只；Top15之后检查共同资格，失败不补位。
- 止盈4.5%、止损8%、最长30交易日、开盘追价最多5%；原衰退替换、T+1、分红权益、交易费用与滑点保持一致。
- 历史容量为执行日前20日的`min(上一日成交额,20日中位数)×1%`，买卖共享证券日额度。研究raw_amount原单位为千元，只转换一次为元。0.5%是原研究敏感性版本，本次不混用。
- 买入只使用开盘前现金及当日到账股息，不复用当天卖款。改变的参数只有每股预算2%/5%/10%。
- 原弱市总仓位15%、非弱市100%保持不变。因此理论名额随仓位比例变成弱市7/3/1只、非弱市50/20/10只。每日Top15不是总持仓上限。
- 两个启动日期分别为2021-10-18和2026-01-05，结束均为冻结数据最后交易日2026-10-16；分别包含1212和188个交易日。首个信号日仅下计划，下一交易日才成交。每种情景包含标准成本、费用和滑点均翻倍两组，共12个账户。

## 这次验证能支持的决策

2%用于12万元账户，会经常遇到不足一手，同时逐步累积到几十只持仓。它不适合把“少量股票、便于管理”作为主要目标的使用方式。

5%可作为重视五年整体收益和回撤的候选：本次五年年化、回撤都优于10%，但理论最多20只、2026平均13.83只，仍不是“最多10只”的组合。

10%可作为明确要求最多10只的候选：2026年初新账户平均6.86只，单股预算不足一手取消降为0；五年回撤大于5%，年化也稍低。若最终选10%，理由应是小资金可执行性和持仓数量符合需求，而不是“所有时期收益都更好”。

三个比例都没有把整手、弱市仓位、行业和历史容量约束放宽。由于弱市名额、持仓路径和复利规模同时变化，这次是三个完整策略配置的比较，不能把全部收益差异解释成只消除了整手取消。
