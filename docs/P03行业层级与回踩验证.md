# P03行业层级与回踩验证

承接[利润保护与启动结构复核](P03利润保护与启动结构复核.md)。研究日期：2026-10-18。继续使用2021-10-18至2026-10-16的1212个市场交易日、5451只沪深证券，指标预热从2020年开始。全部五年用于优化，没有划分验证集或测试集。软件测试只检查程序正确性。

本轮12次资金回放没有找到超过现有最优版的方案，也没有达到胜率至少65%、实际入场最长间隔不超过10日的原目标。二级行业启动增加了交易机会，却降低收益和胜率；接力排序未提高年化和胜率；首次回踩相对直接突破提高了胜率、降低了回撤，但年化与交易频率下降。现有年化11.91%、胜率47.43%的行业初期追价版仍保留为研究基准。它本身的最长入场间隔为59日，不能据此宣称原目标已完成。

实验在运行前固定：现有基准1组、行业层级4组、接力排序4组、价格突破及回踩3组。只有年化高于基准且胜率不低于基准，或同时满足原胜率、频率及正收益要求，才从中选最高年化者追加3组真实资金组合和4次本金敏感性。本轮合格项为0，因此实际总数为12，没有补跑组合、额外本金或新阈值。

层级共同可得对照从11.91%降到10.84%，说明新增同业数据资格本身就改变了交易集合。一级、二级相对强弱排序必须首先与10.84%的共同可得对照比较，两者仍分别降至6.97%和6.20%。不能把覆盖变化与排序效果混成一个结论。接力共同可得对照与现有基准结果精确一致，其他三个接力配置的年化和胜率都低于它；当日参与优先将回撤降至4.98%，存在风险上的取舍，不能说所有指标都变差。

二级行业启动的平均股票仓位从基准33.70%升到40.34%，平均Beta从0.252升到0.319，年化却降至9.51%。更多参与和更高Beta没有带来更高账户收益。首次回踩相比直接突破，平均股票仓位从42.54%降到24.58%，每笔平均收益从0.71%升到0.88%，但平仓数从946降到446、年化从5.67%降到3.62%。单笔表现、参与程度和账户收益需要分别看。

二级行业启动在2024、2025年高于基准，但2022年转负、2023年收益明显降低。首次回踩在2024年为负，而直接突破当年盈利。全期结果不能由某个有利年份代替。

行业层级数据来自已有62份成员文件。7924行中有7543个有效沪深区间、131个二级行业代码；381行因不属于沪深证券范围而排除，另有109只源证券不在冻结研究面板中。纳入日期含当日、退出日期不含当日；缺失、冲突和无法对齐父级的归属不回填。新矩阵与1643日、5451只证券的原面板绑定，共7997281个已知单元、958712个未知单元。证券内冲突、同日同二级行业的多父级冲突及父级错配均为0。

二级行业以独立特征文件接入，没有改写原面板或原技术特征缓存。父级代码与原面板来源核对一致，仅表示这两份来源相容；供应商按SW2021体系回构历史的限制仍在，historical_pit_certified仍为false。代码复核发现的全局父级唯一性缺口已用先失败、后通过的测试修复；真实数据该项冲突为0，修复不能计为策略收益。

信号层复核显示，层级共同可得条件仅从原17063条候选中删去145条，候选日仍为210日；一级、二级相对排序在全部210个候选日都改变了顺序。二级行业启动产生20602条候选、394个候选日，相对基准新增191个整日、失去7个整日，其中4405条候选当日已被保留的一级行业入场否决挡住。更多候选并不等于更多可成交机会。原最长空窗内部，二级行业仅增加了05-19这一个候选日，仍不足以满足两周一次。

接力共同域只删除12条候选，最终账本与基准一致。新参与者优先在210个候选日中的127日改变了首位股票；当日参与优先虽然在93.29%的候选上改了分数，却只在14日改变首位。报告按实际排序变化解释结果，没有把统一加分当成选股改善。

三组层级排序使用完全相同的候选集合。本股和同业必须有21个连续有效市场日且同级行业归属不变；剔除本股后至少5只合格同业，并覆盖当日其他已知成员的60%。同业比较取各自20日累计收益的等权均值，一级、二级相对收益均在同一候选截面转为平均秩。未知同业信息保持未知，不以零收益替代。

二级行业启动组在同一同业可得范围内，仅替换行业入场事件：昨日广度低于65%、今日至少65%、五日增加至少15个百分点、10日动量为正且不超过8%。原一级行业个股资格、低波低换手排序、市场广度至少50%、持仓退出和待单否决均保留。群动广度本身仍包含本股，剔除本股只用于同业资格和相对收益；这不是完整去本股的行业事件回测。

接力组冻结五日前的参与身份，要求六个市场日持续同一一级行业、行情和MA20都有效。旧参与者指五日前已在MA20上方；新参与者指五日前不在上方、今日在上方；当日参与组只看今日，用来检查先后身份是否提供额外信息。优先组改变排序，仍保留其他候选，原低波低换手分数作次级排序。这只是固定五日窗口的价格参与检验，没有认证资金从龙头流向补涨，也没有穷尽全部接力机制。

价格突破组迁移已有P03右侧结构中的价格条件，未迁移财务质量、大单比例等产品门禁。要求61个连续有效市场日，使用原10日整理区、至少5%回调、至少0.5%抬低、整理振幅不超过12%、成交额至少前20日中位数1.2倍，以及均线、追离和结构空间风险门。历史阻力只是价格参照，不是预测目标。

源事件成立时冻结突破位和评分。三臂共享源事件：当日突破发单、首次回踩确认发单、或允许后续有效回踩确认发单。源后1至5日为确认窗口；首次触碰需守位、收盘恢复、成交额不超过突破日，并复核原价格风险与均线条件，失败即注销。第6至8日仅监控旧挂单，最早第9日才能建立新事件；提前失败也不提前解锁。价格事件失效只撤待单，不额外卖出已有持仓。

三臂共同采用8%收盘止盈、8%收盘止损、最长持有30日、2%追价限制，以及90%总仓、5%单股、25%一级行业上限。持仓按一级行业20日动量不为正退出，待单另保留行业广度低于40%的否决。突破源独立于放量反转，也未增加市场广度50%的发单过滤。收盘确认后等下一合格开盘成交，保留T+1、限板、费用和分红等原约束；触发阈值不保证最终成交盈亏。

基准诊断解释了为何单纯改排序不能解决频率。五年有210个候选收盘日、17063条候选，通过共同资格后为14655条，实际740笔、145个买入日。169个候选日超过18只股票、203日同一行业超过5只，确实存在排序竞争；其中65个候选日收盘已有18个持仓，没有新增名额。没有逐笔拒单日志，不能把所有未成交候选都称为资金不足。

2026-05-11至07-30连续58个收盘日没有候选，07-31才产生31条、随后08-03成交。05-25至07-31共49日完全空仓，因此59日最长入场间隔的主体来自缺少信号。987个一级行业核心事件的有效广度成员最少14只、中位121只，没有10只及以下的小组。讨论时提出的三成员噪声机制没有成为实际事件规模的解释。剔除本股会使420条原合格候选失去核心行业条件，涉及17笔原成交确认；这只是敏感性描述，不是可兑现收益。

价格事件诊断保留样本内8688个突破源，其中295个在完整五日内没有进入突破位上方1%以内的回踩范围，7778个发生首触不合格、结构失守或无效行情，1104个曾完成有效首触，累计1527次回踩确认。曾成功首触与后来失败可以重叠，以上计数不能相加。源日行业否决为1160个，末端截尾为0；另有6个样本前源跨入样本边界，但三臂均无样本内跨界成交。

三臂1845笔平仓都唯一关联到价格源。直接突破实际买到的18个无回踩事件，平均净收益14.82%、胜率88.89%；实际买到的370个后来首触失败事件，平均净收益2.26%、胜率51.35%。这说明回踩要求也排除了部分有收益的交易，不能假设被筛掉的都是坏机会。这些分类依赖之后五日的路径，只能事后诊断；其余未成交事件没有被补为零收益，子集利润不能直接当作回踩账户可以挽回的收益。重复回踩453笔交易对应452个源，其中一个源有两笔完整持仓，未通过拆分卖单增加胜率。

现有基准的全部指标、逐日账本、逐笔交易、买入日期及匹配对照CSV与上一轮逐字节相同。独立CSV审计核对本轮12个配置、8766笔平仓，净值、收益、胜率、空窗、费用、滑点与T+1检查通过，全部费用完成核对。重叠交易和重复对照不构成独立样本，审计也不等于完整认证供应商历史或分钟级成交。

996项研究测试通过，两个研究包2490条语句覆盖率100%；93项关联测试通过，Ruff和161个源文件的严格mypy通过。回放前冻结37份源码，包含复用的价格结构与配置源码，回放后指纹一致。未重跑全仓测试。

所有真实行情、交易明细和中间产物留在私有缓存；没有新增远程取数。完整五年经过多轮自适应选择，本轮没有新增样本外有效性或稳定Alpha证据。这里否定的是已冻结的12组实现，不能据此断言所有细分行业、接力或回踩策略无效。小型评分模型、条件续持、残差回归和共享资金尚未在本轮实施；本轮结论不涵盖这些讨论备选。
