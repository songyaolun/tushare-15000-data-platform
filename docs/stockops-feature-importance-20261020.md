# 四个时间权重模型的特征重要度与选股变化

四个模型主要使用同一组特征，重要度排行非常相似；half126 相对增加了价格、趋势和波动特征的增益份额。但排行相似没有带来相同选股：2026 年截至 10 月 16 日的全部 188 个候选日中，equal 与 half126 的行业约束候选名单平均每天有 8 只被替换。

这说明模型行为确实发生了变化，也与前轮观察到的近期样本内收益差异同时存在。本研究没有运行特征收益消融，不能给某个特征分配收益贡献，也不能把近期拟合误差下降写成未来预测能力提升。
