# P03 行业群动初期优化

研究日期：2026-10-18。沿用 2021-10-18 至 2026-10-16 的 1212 个市场交易日、5451 只沪深证券。五年全样本全部用于优化，没有保留验证集或测试集。软件测试检查程序正确性，与策略样本划分无关。

本轮把行业初期策略的胜率从 40.84% 提高到 47.37%，账户年化从 9.52% 提高到 11.39%，最大回撤从 8.78% 降到 5.14%。改动是新增市场广度过滤，将持仓的行业退出条件改为20日动量不为正，固定止盈止损仍为8%。但最长入场间隔为59个交易日，尚未达到胜率至少65%、最长间隔不超过10日的原目标。

这些是同一五年样本内的优化结果。初轮预先固定25组，随后按已记录的结果选择4组交叉，不再追加新阈值。最终还比较3组真实资金组合，以及原行业初期和优化版各自在50万、200万元本金下的结果。全部36次资金回放均保留，其中32次使用100万元本金。

原行业初期来自[上一轮选股与入场研究](P03选股与入场时机优化.md)。它已经独立于放量反转信号。本轮继续使用历史行业成员重建指标，没有把当前概念成分或新闻热度倒填为历史数据。

年化沿用250交易日口径，由逐日账户净值复利计算。每笔平均净收益是交易净收益率的算术平均，不能乘交易次数当作账户收益。期末两组均无持仓、无陈旧报价估值。优化版约每个日历年148笔平仓、29个不同买入日期，但交易集中发生，最长空窗仍不合格。59日跨度来自2026-05-11至2026-08-03，中间连续58个市场交易日没有买入。

2023年和2026年有所改善，但2021年、2022年、2024年和2025年的收益都没有超过原行业初期。不能把全期更好解释成每个年份都更好。

优化版保留原来的行业启动和选股条件。行业广度由昨日低于65%上穿至至少65%，五日内提高至少15个百分点，行业10日收益为正且不超过8%。个股20日收益在0%至10%、当日涨跌在−1%至3%、收盘不低于MA20的98%；20日波动分位不超过60%、平均换手分位不超过70%，优先低波动和低换手。

行业广度是历史行业成员中站上MA20的比例，每日至少3个有效成员且覆盖已知成员的60%。个股比较要求21个市场日连续有效；分位排名基于技术和行业数据完整的截面，共同成交资格再由执行器过滤。行业初次走强比较同一行业的历史指标，股票换行业不会制造上穿事件。

新增入场条件是当日全市场广度至少50%，即行情有效且MA20已知的证券中，收盘严格高于MA20的比例至少一半。这个条件使用发单日收盘已经知道的信息，随后在合格开盘成交。等待期间不因市场广度低于50%单独撤单，仍按原行业否决条件和三日有效期处理。它不要求事后认定牛市，也不使用未来行业恢复情况。

已有持仓的行业退出由“行业广度低于40%或20日动量不为正”改为“行业20日动量不为正”。入场否决和待买订单撤销仍保留原条件，因此放松持仓退出不会让原本禁止的买单通过。固定止盈8%、止损8%、最长持有30日及仓位上限保持原值；每股5%、行业25%、目标总仓位90%。收盘确认退出后等下一合格开盘，仍受T+1、跌停和公司行动约束。

8%止损是触发阈值，不是最终亏损上限。优化版26笔固定止损平均实际亏损9.89%；166笔固定止盈平均盈利11.68%。模型只在收盘检测，触发时收盘价可能已越过8%阈值，还要叠加下一可成交开盘的跳空、成交限制和费用。参数没有在持仓期间放宽。

四组交叉选用初轮年化最高的两个质量条件，以及年化最高的两个管理调整。6%止损单独使用时胜率略低于原策略，保留这项交叉是检查交互效果，不能说它独立改善了胜率。四组都未增加新阈值。

市场广度过滤的作用最清楚。单独增加50%门槛时，行业退出现金亏损减少26.23万元，固定止损亏损减少5.72万元，固定止盈也少赚21.47万元。总净利润增加10.66万元。新旧账户的成交机会和股数都发生变化，不能靠在原交易表里删掉亏损单得到这个结果。

诊断也不支持普遍延迟卖出。原979笔行业退出中，695笔亏损、284笔盈利；退出后5日和10日开盘毛收益均值分别为−0.317%、−0.050%。完全取消行业退出虽然把胜率提高到52.21%，年化却降至8.00%，回撤扩大到12.63%。均线上行、KDJ上行、BOLL位置限制和延后确认也都没有改善原策略年化。

优化版的因子回归年化截距为5.26%，未校正95%区间为2.00%至9.10%；原行业初期为4.47%。因子包含昨日组合Beta对应的市场收益、昨日持仓行业相对市场收益，以及规模和动量代理。分别估计的区间不能直接证明Alpha差异。相对原策略的配对日均收益差按250日折算为1.64个百分点，20日块、300次重采样区间为−3.27至5.79个百分点，仍跨过零。这个量不等于两组CAGR之差。

全样本上涨阶段，优化版平均仓位61.86%、平均Beta为0.476；下跌阶段分别为7.91%、0.061。阶段统计按昨日状态解释今日收益，属于事后归因。策略本身只使用实时可知的广度条件，没有新增事后阶段开关。本轮也没有证明上涨Beta被放大：全期平均Beta反而下降。

新增程序把入场否决矩阵与持仓退出矩阵分开；默认值保留旧行为，配置哈希分别记录两者。原控制组的1212行日账本、1239笔平仓、1239笔买入及1217条可匹配交易对照，除策略标签外与上一轮完全一致，全部指标也一致。

研究模块596项软件测试通过，1929条语句覆盖率100%；另有52项关联测试通过，Ruff与严格mypy通过。独立CSV审计覆盖32个百万元配置、39696笔平仓；4个额外本金结果按真实本金另行核算收益、现金、胜率和空窗，没有冒用固定百万元审计。没有重跑全仓测试。

全部数据来自已有缓存，本轮未新增远程行情请求。日线成交仍是假设模型，历史ST、部分公司行动和历史概念成分未完整认证。多轮选择均使用同一五年样本，因子区间和收益差区间未做策略选择校正，不能据此宣称样本外有效或实盘收益已被验证。
