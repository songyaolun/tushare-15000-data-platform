# 每日筹码及胜率

接口：cyq_perf

描述：获取 A 股每日筹码平均成本和胜率情况，每天 18～19 点左右更新，数据从 2018 年开始。

限量：单次最大 6000 条，可以分页或者循环提取。

积分：5000 积分每天 20000 次，10000 积分每天 200000 次，15000 积分每天不限总量。

此文件是[官方接口文档](https://tushare.pro/document/2?doc_id=293)的 Markdown 离线重放节选。省略了算法说明和数据样例；字段全表见同目录上级的官方 HTML 快照。

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 股票代码 |
| trade_date | str | N | 交易日期 |
| start_date | str | N | 开始日期 |
| end_date | str | N | 结束日期 |

```python
pro.cyq_perf(ts_code="600000.SH", start_date="20220101", end_date="20220429")
```
