Tushare 指数代码标准化说明

适用范围：Tushare Pro 全部指数类接口（如 index_basic、index_daily、index_dailybasic、index_member 等），代码参数统一为 ts_code，格式为 代码 + "." + 来源后缀。

1. 标准化原则

  1. 统一参数名：所有接口中指数代码均通过 ts_code 传入，必须携带后缀，禁止使用裸代码。
  2. 后缀标识"编制机构/数据来源"：与股票后缀标识交易所不同，指数后缀标识的是指数编制方或数据源（如中证、国证、申万等），并非全部对应交易所。
  3. 同码不同源需靠后缀区分：同一数字代码在不同体系下含义不同（如 000300.SH 与 399300.SZ 均指沪深300，但归属不同数据源；000001.SH 是上证指数而 000001.SZ 是平安银行股票）。

2. 指数后缀标准化总表

后缀 指数来源/编制机构 代码特征 典型示例 覆盖范围说明
.SH 上海证券交易所指数 以 000 开头为主 000001.SH 上证指数、000016.SH 上证50、000688.SH 科创50 上交所发布的市场规模、板块类指数
.SZ 深圳证券交易所指数 以 399 开头为主 399001.SZ 深证成指、399006.SZ 创业板指、399005.SZ 中小板指 深交所发布的市场规模、板块类指数
.CSI 中证指数有限公司 000/930/931/H 开头等 000300.CSI 沪深300、000905.CSI 中证500、930697.CSI 家用电器 规模、行业、主题、策略、债券等中证系列指数
.CNI 国证指数（深证信息公司） 399 / 980 开头为主 399311.CNI 国证1000、399006.CNI（部分与深交所同码） 国证规模、行业、主题系列指数
.SI 申万宏源（申万指数） 801 开头为主 801010.SI 申万农林牧渔、801080.SI 申万电子、801780.SI 申万银行 申万一级/二级/三级行业指数及风格指数
.CI 中信证券（中信指数） CI005 开头为主 CI005001.CI 中信石油石化、CI005018.CI 中信汽车 中信一级/二级/三级行业指数
.TI 同花顺指数 8 开头为主（如 885xxx、886xxx） 885431.TI 同花顺人工智能、886002.TI 同花顺行业指数 同花顺概念板块、行业板块指数
.DC 东方财富指数 BK 开头为主 BK0475.DC 银行、BK1031.DC 概念板块类 东财行业板块、概念板块、地域板块指数
.TS Tushare 自编板块指数 Tushare 自定义编码 8XXXXX.TS 等 Tushare 板块 Tushare 官方整理的板块/主题分类指数

3. 按用途选择数据源的建议

使用场景 推荐后缀体系 理由
宽基指数行情（上证指数、深证成指等） .SH / .SZ 交易所官方口径，历史最长
跨市场规模指数（沪深300、中证500/1000） .CSI（或 .SH 同码） 中证为官方编制方，衍生指标齐全
行业归属与行业比较分析 .SI（申万）或 .CI（中信） 卖方研究主流行业分类标准
概念/题材热点跟踪 .TI（同花顺）/ .DC（东财） 概念板块覆盖细、更新快
Tushare 生态内板块统计 .TS 与 Tushare 板块成分接口直接配套

4. 关键注意事项

  1. 必须带后缀查询：000300 裸代码无法唯一定位；
  2. 区分指数与股票：沪市 000 开头 + .SH 为指数（股票为 600/601/603/688 等）；深市 399 开头 + .SZ 为指数（000/002/300 开头 + .SZ 为股票）。
  3. 同码多源：国证部分指数与深交所指数代码重叠（399xxx），需通过 .CNI 与 .SZ 区分口径。
  4. 权威清单获取：各体系完整指数列表建议通过 index_basic(market='SSE'/'SZSE'/'CSI'/'CNI'/'SW'/'CICC'...) 接口拉取，以接口返回为准。
  5. 权限差异：申万、中信、同花顺、东财等指数在 Tushare 中通常需要相应积分权限，使用前请确认账号权限。

说明：表中"代码特征"与示例为各体系常见编码规律，个别指数可能存在例外，最终以 index_basic 接口返回的 ts_code 为准。
