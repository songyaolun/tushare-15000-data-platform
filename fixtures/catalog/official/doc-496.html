标准仓单到期数量

接口介绍

接口：fut_rcpt_mat
描述：获取上海期货标准仓单到期数量数据（其他交易所上线中）
限量：单次最大3000条，可根据代码或日期循环提取
积分：需要5000积分可以调取，具体请参阅积分获取办法

输入参数

名称 类型 必选 描述
trade_date str N 交易日期（YYYYMMDD）
ts_code str N 期货代码
start_date str N 开始日期（YYYYMMDD）
end_date str N 结束日期（YYYYMMDD）

输出参数

名称 类型 默认显示 描述
trade_date str Y 交易日期（YYYYMMDD）
exchange str Y 交易所
fut_code str Y 期货代码
fut_name str Y 品种名称
unit str Y 单位
cur_month float Y 当月到期数量
next_month float Y 一个月到期数量
next_two_month float Y 两个月到期数量

代码示例

# 导入sdk包
import tushare as ts

# 配置凭据，如果已全局配置了，可以忽略。
ts.set_token('<REDACTED>')

# 获取接口实例
pro = ts.pro_api()

# 拉取接口(fut_rcpt_mat)数据
#获取AD所有的数据
df = pro.fut_rcpt_mat(ts_code='AD')

# 获取2026年9月所有数据
df = pro.fut_rcpt_mat(trade_date='20260904')
print(df)
