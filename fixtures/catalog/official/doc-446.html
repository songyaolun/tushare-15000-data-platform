自选股组合查询

接口介绍

接口：p_list
描述：便于用户在基于AI应用或Vibe Coding过程中产生的选股结果形成长期记忆，Tushare提供了自选股组合功能。本接口可以查询你的自选组合信息，不加参数查询出所以自定义组合

输入参数

名称 类型 必选 描述
name str N 组合名称

输出参数

名称 类型 默认显示 描述
id int Y 主键
name str Y 名称
desc str Y 描述
create_time datetime Y 创建时间
update_time datetime Y 修改时间

代码示例

# 初始化pro接口实例
pro = ts.pro_api()


# 查看我的组合列表
df = pro.p_list()
print(df)

# 查看某个组合的成份列表
df = pro.p_get(name="我的股票池", fields="ts_code,create_time,update_time")
print(df)
